## 1차 (2026-10-04)
질문: 난이도 이름, 노선 지도, 보상 A/B/C, 힌트 방식, 샘플 문제 3개, 학습 시간, 꼭 있었으면/없었으면 하는 것

### 도윤 (#1) 답변 요약
- Q1 난이도 이름: 순서는 좋음(청룡이 마지막인 건 "맞다"). '마을버스'는 아기 같다는 반응. 김해경전철(무인 운전)을 난이도 단계에 넣어 달라고 함 — 좋아하는 열차를 복습 전용으로 두면 반발이 생길 수 있음.
- Q2 노선 지도: 재밌어하고, 환승역 융합 문제를 특히 좋아함. "변화와 관계"는 무슨 말인지 모름 → 영역 이름을 아이 말로 바꿀 것. 역 순서가 틀리면 바로 신뢰를 잃음.
- Q3 보상: **C = A(열차 카드 + 혼자 운행 도장) + 승급 시험.** 포인트와 순위는 싫다고 함.
- Q4 힌트: '연습장 먼저' 안내가 매번 나오면 귀찮음. 두 번 틀렸을 때 힌트를 누르고 싶어함. ④단계는 "진 기분" → 빈칸 하나만 남기는 형태로.
- Q5 샘플 문제 (재미 / 진짜 부산 같다):
  - 서면→연산: 정답 8분. 2 / 5. 너무 쉬움 → 환승 시간 같은 단계를 하나 더 붙일 것
  - 배차 최소공배수: 정답 7:24. 4 / 3. 실제 버스 번호를 원함
  - 바둑판 최단경로: 정답 10가지(처음엔 9개로 하나 빠뜨림). 5 / 2. 해운대는 바둑판이 아님 → 센텀·명지처럼 실제로 바둑판 모양인 동네로
- Q6 분량: 15분, 8문제쯤. 같은 유형 반복, 3연속 오답, 승급 시험 탈락에 짜증. 탈락하면 재도전 시점과 약점 연습을 보여줄 것.
- Q7: 꼭 있었으면 = **실제 노선도에서 푼 역에 불이 켜지는 것.** 절대 없었으면 = 만화 캐릭터의 "잘했어요~♡" → 칭찬은 "서면역 개통 완료" 같은 사실형으로.

### 서준 (#2) 답변 요약
- Q1 난이도 이름: 마을버스 시작은 좋다고 함. '좌석버스'(1003번 같은 것)를 넣어 달라고 함. 산천과 SRT를 한 칸에 둔 건 어색함. 6단계부터 버스가 사라지면 실망할 위험 → 상위 단계에도 버스 테마를 곁들일 것. 다음 단계 차량 그림을 늘 보여줄 것.
- Q2 노선 지도: 동네 역이 나오면 좋다고 함. 영역 이름은 읽지 않음 → 역 이름과 "다음 역까지 N문제"만 보이면 됨. **'복습선'은 기피 대상** → 복습은 일반 노선 중간에 "임시 정차"로 섞을 것. 환승역은 두 노선을 다 뚫어야 열리게.
- Q3 보상: B에 끌리지만, 설계 관점에서는 C를 추천. A를 기본으로, B에서는 승급 시험 합격 배지 하나만. **레어도는 운이 아니라 행동으로**(혼자 운행 도장 5개 = 금테 카드). 포인트와 순위는 뺄 것.
- Q4 힌트: 연습장 안내는 귀찮아서 그냥 넘김. 문장이 길면 ④까지 누름. 힌트를 바로 누르는 순간 = 문장 세 줄 이상 / 처음 보는 유형 / 한 번 틀린 직후. 제안: ④ 뒤에는 쉬운 쌍둥이 문제를 주고 혼자 풀면 도장 회복. "한 번만 더 해 보면 도장!" 문구. 힌트를 썼다고 감점하면 찍기로 바뀜.
- Q5 샘플 문제 (재미 / 진짜 부산 같다):
  - 서면→연산: 10분 → 스스로 고쳐 8분. 3 / 5. 칸 수와 역 수를 헷갈리는 오류가 그대로 나옴 → 진단 문제로 좋음
  - 배차 최소공배수: 7:24이지만 글자가 많아 찍을 뻔함. 3 / 2. 정류장 이름과 버스 번호가 필요하고, 배차는 '가상'으로 표시할 것
  - 바둑판 최단경로: 6가지(오답). 4 / 2. 교차로마다 가짓수 적기 힌트, 손가락으로 경로를 그리는 화면이 필요
- Q6 분량: 10분, 5문제. 같은 유형 세 번이나 두 번 연속 오답이면 그만하고 싶어함 → 같은 유형은 최대 2개 연속, 2연속 오답이면 쉬운 문제를 끼워 성공으로 끝내기, 끝에 "다음 역" 예고.
- Q7: 꼭 있었으면 = **풀면 내 버스가 지도에서 움직이는 것.** 절대 없었으면 = "땡!" 소리와 빨간 X → "버스가 잠깐 멈췄어요. 다시 출발해 볼까요?"

## 2차 (2026-10-04)
질문: 11단계 사다리 확인, 운행 흐름과 운행 일지, 열차 카드, 승급 시험과 탈락 처리, 고친 문제 4개, 첫 화면과 배치고사, 힌트 규칙의 허점

### 도윤 (#1) 답변 요약
- Q1 11단계: 마을버스 제외와 경전철 추가는 좋음. **경전철(2량)이 도시철도보다 위인 건 어색함** → 그 자리에 둘 근거를 보여주거나 순서를 바꿀 것. 해변열차·SRT 특별 카드는 좋음.
- Q2 운행 흐름: 6문제 좋음. 운행 일지에 **"정시 도착!"** 같은 철도식 시간 표현과 **틀린 문제 다시 보기**를 원함. 맞힌 수는 크게 안 써도 됨. 기준 시간은 넉넉하게, 화면에는 숨길 것(시간 압박 방지).
- Q3 열차 카드: 편성 번호, 만든 회사, 실제 같은 그림을 추가하고 싶어함. 출처는 작게. 금테 기준은 높은 단계일수록 늘리기(청룡은 10개). 뒷면 문제가 앞면 제원을 쓰면 좋음.
- Q4 승급 시험: 바로 재도전할 수 있으면 덜 화남. 이름은 **"운행 면허 시험"**(시승 운행과 헷갈리지 않게), 합격하면 "○○호 운행 허가", 탈락하면 "정비 후 재출발". 재도전 문제는 숫자를 바꿔 낼 것.
- Q5 고친 문제 (재미 / 진짜 부산 같다 / 나아졌나):
  - 서면→연산+환승: 11분 정답. 3 / 5 / 나아짐
  - 시간표 채우기: 7:24 정답. 3 / 4 / △ — **빈칸이 딱 답에서 끝나서 답이 그냥 보임** → 칸을 더 길게, 또는 "8시까지 몇 번 같이 출발?"
  - 교차로 숫자 적기: 10 정답. 4 / 3 / 나아짐 — 처음부터 주면 쉬움 → **힌트 ②에서만 이 화면을 보여줄 것**, 왜 1인지 설명하는 칸
  - 36km 순환 노선: 처음에 10을 말할 뻔하다가 18 정답. 5 / 3 / 가장 좋음 — 오답 유형이 뚜렷함(10, 13, 21, 23) → 오답별 피드백. 실제 순환형 노선 이름이 있으면 사용
- Q6 첫 화면: **불이 다 꺼진 부산 전체 노선도** → 곧바로 시승 운행. 긴 설명은 넘김. 12문제는 조금 김 → 차량 이동으로 진행 정도를 보여줄 것.
- Q7 힌트 허점: **"0 넣고 ② 열 거예요"** → 대응책: 대충 넣은 답(빈칸, 0, 문제의 숫자 그대로)을 감지해 연습장으로 돌리기 / ②는 답 대신 식 한 줄이나 첫 단계를 입력하면 열기 / 대충 넣어서 ②를 열면 그 문제의 도장을 받을 수 없게.

### 서준 (#2) 답변 요약
- Q1 11단계: 좌석버스 추가와 산천·청룡 분리는 좋음. **마을버스가 빠져서 아쉬움** → 시승 운행이나 연습 차량으로 남길 것. 시티투어 2층버스 카드를 원함. 특별 카드는 얻는 조건이 보여야 함(숨기면 뽑기처럼 느낌).
- Q2 운행 흐름: 6문제는 할 수 있음. **4번째쯤 어려운 문제가 나오면 그만두고 싶음** → 어려운 문제는 3~4번째, 마지막은 쉽게. 운행 일지에 **"오늘 몇 km 달렸어요"**를 원함. 맞힌 수는 3개뿐이면 기분 나쁨 → 부모 화면에만. 중간에 끄면 "○○역 정차 중"으로 저장.
- Q3 카드: 버스 카드 항목 = 노선 번호, 종류와 색, 기점–종점, 정류장 수, 노선 길이, 차종(전기/CNG/저상), 처음 생긴 해, 기준 연도. 도장은 진행 막대(3/5)가 보여야 함. 자랑하고 싶어함 → 카드를 이미지로 저장하는 기능(개인정보 없이).
- Q4 승급 시험: "시험"은 무섭다고 함 → '불합격' 대신 "정비가 필요해요 → 정비 운행". 합격하면 새 차량이 차고에서 나오는 연출. 재도전 문제는 숫자를 바꿀 것.
- Q5 고친 문제 (재미 / 진짜 부산 같다 / 나아졌나):
  - 서면→연산+환승: 11분 정답. 3 / 5 / 조금
  - 시간표 채우기: 7:24 정답. 4 / 4 / 많이 — **칸을 다 채워야 선택지가 열리게**(안 그러면 찍음)
  - 교차로 숫자 적기: 10 정답(1차엔 6). 4 / 3 / 많이 — 처음 두세 칸은 직접 그려서 세게 하고, 규칙은 스스로 찾게. 칸을 채우면 해당 경로가 빛나게
  - 36km 순환 노선: 21로 틀렸다가 힌트를 보고 18. 2 / 2 — 글이 길어서 두 번 읽음 → 문장을 줄이고 원 그림에 옛(파랑)·새(주황) 정류장을 찍게. 일직선 버전은 '+1 실수' 진단 문제로 따로 쓸 것
- Q6 시승 운행: 12문제는 많음(8번째쯤 지루) → 적응형으로 8~10문제, 중간에 "지금 ○○ 차량 후보!" 보여주기. 첫 화면은 지도 + 내 차량 + 출발 버튼. 이름과 차량 색 고르기로 애착 만들기.
- Q7 꼼수 (가장 중요):
  1. "1" 넣고 ② 열기 → ②를 열 때 "어디까지 해 봤어?"를 묻거나, 동떨어진 답이면 ①로 안내

## 커리큘럼 전문가 자문 1차 (2026-10-04) — 상세: docs/curriculum/ (README.md에 목차) → SPEC v0.6
- 교육적 위험:
  1. **최우선: "정답마다 다음 역"과 "역 1개 = 개념 1개"가 부딪침** → 한 문제로 개념 통과. 정답마다 역 사이 구간을 한 칸씩 가고, 역 점등은 숙달 기준을 채웠을 때만
  2. 11단계를 학생 한 명의 전체 등급으로 쓰면 개념마다 다른 천장과 안 맞음 → (역, 단계) 두 축, 역마다 천장, 7단계 이상은 그 역과 선수 개념 도구로 풀리는지 검수
  3. 노선은 직선, 개념은 그래프 → 열리는 조건은 그래프, 노선 순서는 추천 순서로만
  - 그 밖에: 1단계는 한 단계 풀이(진단용), 정비창 점검(계산 묶음) 허용, 운행 3~4번은 현재 단계 +1까지
- 개념 그래프: 1~2학년 기초 B01~B11("출고 선로"), 1호선 40노드에 31개 성취기준, 2호선 약 40, 3호선 약 12, 4호선 약 10, 동해선 23. 환승 융합 4곳. 중학교 확장 순서 초안.

- 총평: 타이머·순위·뽑기·빨간 X·캐릭터 칭찬 없음, 단계 숨김, 칸이 줄지 않음, 정차 저장, 신고 버튼은 발달심리 관점에서 잘 만듦. 남은 위험은 보상이 **"어디까지 왔는지 알려 주는 것"에서 "한 번 더 하게 당기는 것"으로 넘어가는 지점**. 선 긋기 제안: 알려 주는 보상(켜진 역, km, 카드, 오늘 배운 것)은 허용, 당기는 보상("○○까지 2km!", "한 번만 더 하면 금 도장!", 끝 화면의 큰 "한 번 더" 단추, 하루 상한 없음)은 금지.

- 사용 시간: 하루 운행 수("막차", 부모가 1~4, 기본 2), 넘긴 문제 2개면 쉬어 가기 제안, 다음 역 예고는 장소만.
- 부모 화면: 숫자보다 문장, 문제보다 개념, 하루보다 주간. 아이 고지 문구 교체. 늦은 시각 운행은 수면용으로만 표시.
- 빠진 보호 장치: 밤 사용, 눈("창밖 먼 곳을 20초"), 형제 비교 금지.

- **부모 결정이 필요해서 보류한 것**: (1) 하루 운행 수 "막차"(기본 2) (2) 면허 시험을 없앨지(A안) 시험 대신 제안형(B안)으로 할지 (3) "당기는 보상 금지" 선 — 게이미피케이션 자문 1차와 함께 정리해 부모에게 묻기로.
- 아동 심리 자문 보충 — 보류 세 가지를 부모에게 물을 때 함께 전할 "최소선":
  1. 막차: 횟수는 부모가 정해도 됨. 지킬 것은 멈추는 신호를 시작할 때 한 번만, 못 한 운행은 다음 날로 쌓지 않기. 상한을 두지 않더라도 끝 화면의 "오늘은 여기까지" 우선 배치는 유지.
  2. 면허 시험: B안도 괜찮음. 단 "같은 날 재시험 금지"와 "탈락이라는 낱말 없음"은 지키기(계속 틀리면 짜증 내는 아이에게 탈락 → 재시험 → 다시 탈락으로 이어지는 하루가 가장 큰 위험).
  3. 선 긋기 판단 기준: "그 장치를 빼도 아이가 어디까지 왔는지 아는가" — 안다면 그 장치는 정보가 아니라 끌어당기는 장치.

## 6차 라운드 (2026-10-04) — 아동 심리·게이미피케이션 자문 질문
### 도윤 (#1)
- Q1 끝 단추: "솔직히 한 번 더 운행 누를 거예요" → 실제 제한은 부모가 정한 횟수. 막차 예고는 "미리 알면 덜 화나요". **가장 큰 갈등은 운행 중간에 끊기는 것**("역 바로 앞인데!") → 부모 쪽 "이번 운행 끝나면 마치기" 기본, 아이 화면에 "이번 운행이 끝나면 쉬어요". "내일 첫차에 만나요"에 다음 출발역 함께.
- Q2 금 도장: 오래 버티다 짜증 → 이탈, 또는 찍기 위험. 두 번째에 맞히면 "억울해요, 제가 푼 건데" → 일지에 "스스로 고쳐서 도착" 같은 행동 기록(메달 아님). 막혀 있을 때 "① 노선 확인은 써도 금 도장이 그대로예요" 안내.
- Q3 면허: 친구에게 자랑. 동생이 더 높으면 짜증 → 형제 면허 나란히 금지. 저절로 오르는 건 좋지만 오르는 순간이 멋있었으면 → **면허증 발급 연출**(이름, 발급일, 운행 기록).
- Q4 소재 고르기: 거의 늘 열차. **"계산만 고르면 불이 늦게 켜진다고요? 그럼 절대 안 골라요. 벌 받는 거잖아요."** → 진행에 차이를 두지 말 것(같은 진행 + 이야기 문제엔 역 사실 하나 같은 다른 종류의 덤).
- Q5 차량: 청룡이 1호선 위를 달리면 이상함 → **노선도 위는 그 노선의 실제 차량, 고른 카드는 출발 장면·일지에**(고증).
- Q6 탐험: 막차 뒤에도 열어 봄. 보고 싶은 것: 역 번호, 환승, 개통 연도, 출구 수, 지하 몇 층, 섬식/상대식 승강장, 다음 역까지 km → FACTS 후보.
- Q7 도감: 사진, 역 번호, 이름 뜻(낫개), 생긴 해, 깊은 불. "처음엔 어려웠던 문제 → 지금은 풀어요"는 기분 좋음, 엄마가 봐도 됨(자랑), 숨기기는 안 쓸 듯 → 기본 공개, 숨기기 가능. 부모가 "처음엔 못 했네" 식으로 말하지 않게 안내 필요.
- Q8 깊은 불: (가) 미리 알림이 좋음("보스 문제 같아요"), 한 달은 너무 김, "다 채우고 싶어요" → "도전 문제예요(틀려도 불은 그대로)", 기간 대신 "다음에 이 역을 지날 때 다시 나와요". (아동 심리 자문은 (나) 권고 — 상충)
- Q9 가족 문제: "나중에"면 서운, 나중에 풀어 주면 괜찮음, 엄마가 풀었는지 알고 싶음 → 비동기 제안. (아동 심리 자문은 기다림 상태 없음 권고 — 상충)
- Q10 질리는 때: 2~3주, 비슷한 문제 반복과 2호선이 너무 멀 때. 다시 하게 만드는 것 1등 **실제로 타 본 구간 표시**, 2등 진짜 철도 소식, 3등 가족에게 문제 내기. 1호선 중간(서면 근처)에 2호선 일부를 열어 변화 주기 제안.

### 서준 (#2)
- Q1: 그만두는 이유가 엄마가 아니라 "운행 시간표"면 덜 짜증 남. 남은 운행이 0이면 "한 번 더" 대신 "내일 첫차" 단추. 꼼수: 막차 중간에 끄기(→ 시작할 때 세고 다음 날 이어 타기 — 이미 그렇게 구현), 다른 프로필로 타기, 기기 날짜 바꾸기(→ 부모 화면에 조용히 표시, 구현).
- **Q2 가장 시급한 허점: 틀린 직후 앱을 끄면 다음 운행에 같은 문제를 "첫 시도"로 다시 받아 금 도장** → **실제 코드 버그였음. 정차 저장에 틀린 횟수와 연 힌트를 넣고 이어 타기로 처리하도록 고침 + 회귀 테스트.** 두 번째에 맞히면 아무것도 없으면 "두 번째는 의미 없다"로 배워서 첫 오답 뒤 바로 힌트 ④ → 이름 있는 기록 필요. 오래 멈춤 같은 짜증 신호에는 "① 노선 확인을 봐도 금 도장은 그대로" 안내(시간을 보상이 아니라 도움 안내에만).
- Q3: 형제 비교 위험, 면허증 발급 연출, 버스 면허에도 특별한 장점.
- Q4: 거의 늘 버스, 피곤하면 계산만. "계산만이면 불이 늦게"는 억울 → 같은 속도 + 이야기 문제엔 다른 종류의 덤. 꼼수: 쉬운 쪽 알아채기(고르는 화면엔 소재 이름만), 보고 나서 다시 고르기(고르면 확정).
- Q5: "내 차니까 내 맘대로" — 노선도 위를 달려도 괜찮고 "특별 시승 운행" 표시 정도. (도윤·하린과 다름)
- Q6: 막차 뒤에도 봄. 역 근처 버스, 출구 수. 부모가 둘러보기도 끌 수 있게.
- Q7: 버스 번호, 재밌는 사실. 진짜 어려웠던 건 숨기고 싶을 수도 → 쪽마다 "가족에게 보여 주기". 꼼수: 일부러 틀려서 성장 이야기 만들기 → 개수 세지 않기, 보상·완성 조건에 넣지 않기.
- Q8: 처음엔 (가)지만 틀리면 창피 → (나)가 낫다. 한 달 뒤 재출제는 괜찮음(쌍둥이 문제로).
- Q9: "나중에"면 다음에 안 만듦 → "가족 우편함" 비동기. 아이가 만든 문제의 답을 앱이 먼저 확인. 자유 글 칸에 개인 정보 위험.
- Q10: 2~4주차, 1호선 중간 구간. 재방문 장치 ① 실제로 타 본 구간 ② 진짜 부산 교통 소식 ③ 가족에게 문제 내기(초반만). 탄 구간 표시는 GPS 없이 손으로, 보상 걸지 않기.

### 하린 (#3)
- Q1: 다 맞혔으면 "오늘은 여기까지", 마지막에 틀렸으면 무조건 "한 번 더"(틀린 채 끝나면 자기 전까지 생각남). 막차에서 틀린 문제를 "내일 첫차 첫 문제로 나와요"라고 약속해 주면 훨씬 쉽게 끌 수 있음 → **구현**.
- **Q2 금 도장: 엄청 오래 버티다 짜증, 엄마에게 몰래 물어볼 것**. 숫자 하나 잘못 눌러 금 도장이 날아가면 "미칠 것 같아요". 바람: 제출 전 "확인했어요 / 다시 볼래요", 틀린 순간에 "같은 유형을 다음에 맞히면 금으로 바뀐다"는 안내, 오래 고민하면 "힌트 ②를 봐도 끝까지 푼 문제로 남아요".
- Q3: 자랑은 잘 안 함, 동생이 높으면 엄청 속상. 저절로 오르면 "진짜 잘해서 오른 거 맞나?" → **오른 근거를 보여 주기 — 구현(면허증에 "○○·○○·○○역에서 이 단계 문제를 풀어서 올랐어요")**.
- Q4: 거의 늘 지리. 소재가 달라도 어려움이 정말 같아야 함.
- Q5: 1호선 위 청룡은 이상함, 동생이 진짜인 줄 앎 → 기본은 진짜 1호선 차량, 카드 차량엔 "상상 운행" 표시(지어낸 숫자 밑줄처럼 일관된 표시).
- Q6: 구·동, 역명 유래, 지하 깊이, 실제 역 사이 거리 vs 노선도 칸(축척), 가까운 산·바다·강·다리, 지나는 구 → FACTS 후보.
- Q7: 실제 사실 카드, 처음 켠 날, 대표 문제와 그때 연습장, 지도 조각. "처음엔 어려웠던"은 좋지만 조금 부끄러움 → 내가 보여 주고 싶을 때만, 숨기기. 문구는 "자란 문제", "이제 내 거가 된 문제"처럼 앞을 보는 말.
- **Q8 깊은 불: (가)지만 "도전할래? / 다음에 할래"를 고를 수 있게 + "틀려도 지금 켜진 불은 그대로예요". 몰래 내는 시험은 "숨은 평가"(정시 도착과 같은 문제). 한 달은 너무 김 → 며칠~1주 뒤 쌍둥이 문제. 노선도에 나란히 보이면 새 역 대신 채우기만 할 것 → 도감 안에만.**
- Q9: 언제인지 모르는 "나중에"가 제일 서운 → 보내 두고 시간 날 때, 풀면 알림, 부모가 "언제 풀게" 답장, 아이가 해설 써 주기.
- Q10: 질리는 때 — 비슷한 유형 반복, 다음 카드가 멀어 보일 때, **신고했는데 아무 일도 안 일어날 때(제일 싫음)**. 다시 하게 — 새 노선, "네가 신고한 문제를 고쳤어요" 알림, 내 문제가 앱 문제로 채택, 경시 특별 운행, 가 본 역(부모가 손으로).

### 6차 즉시 반영
- 이어 타기 버그 수정(정차 저장에 틀린 횟수·힌트) + 회귀 테스트.
- 일지에 "다시 생각해서 맞힌 문제 N개"(세 학생 모두 "억울해요"), 작은 사실들은 한 줄로 묶어 다섯 줄 유지.
- 면허증 발급 연출(이름·발급일·오른 근거 역 이름).
- 막차 뒤 넘긴 문제가 있으면 "오늘 넘긴 문제가 첫 문제로 나와요".
- 기기 날짜가 뒤로 바뀌면 부모 화면에 조용히 표시.

### 상충 → 자문에 판단 요청
- 깊은 불: 도윤 (가) 예고, 서준 (나) 몰래가 낫다, 하린 (가) + "도전할래?/다음에 할래" 선택 + 며칠 뒤 쌍둥이, 아동 심리 자문은 (나) 권고.
- 가족에게 문제 내기: 세 학생 모두 비동기(우편함, 풀면 알림) 원함, 아동 심리 자문은 기다림 상태 없음 권고.
- 금 도장 첫 시도 기준과 실수 공포: 제출 전 "확인했어요/다시 볼래요", 오래 멈추면 도움 안내, 틀린 순간 "다음에 금으로 바뀔 수 있어요" 안내 — 아동 심리 자문 H4("보상을 내미는 문구 금지")와 맞는지.
- 노선도 위 카드 차량: 도윤·하린 "이상함"(고증), 서준 "괜찮음".
- 부모가 운행 중간에 끄게 하는 문제: "이번 운행 끝나면 마치기" 기능.

## 자문 3차 (2026-10-04) — 학생 6차 상충 판단: docs/wellbeing/wellbeing-review-03.md, docs/engagement/engagement-review-03.md → SPEC 3.8, 10장
- 아동 심리 자문이 학생 답을 보고 2차 권고 두 가지를 바꿈: 깊은 불은 몰래가 아니라 선택형 예고("숨은 평가"는 옳은 지적), 가족 문제는 비동기(상처는 기다림이 아니라 언제 끝날지 모르는 기다림에서 옴).
- 두 자문이 같은 결론: 금 도장 "첫 시도" 조건 제거 → 힌트 ① 이하·두 번 안에(코드에만 있던 조건), 제출 전 매번 확인 반대 → 단추에 답 보이기, 노선도 위는 실제 차량, "이번 운행 끝나면 쉬기" 강하게 채택.
- 게이미피케이션: 소재 고르기 km 절반 제안 철회(같은 칸·같은 km), 버스 면허에 기능상 특권은 반대(차량별 출발 장면과 카드 사실로), 질리는 시점은 콘텐츠 일정으로(서면 즈음 2호선 시범 구간).
- 구현: 금 도장 두 번 안에, 오래 멈출 때 도움 안내(2분, 한 번, 금 도장 언급 없음), 답 내기 단추에 답 표시, 운행 띠 [부모] → "이번 운행 끝나면 쉬기"(그 운행이 막차, 쉬운 문제 더 끼우지 않음). 회귀 테스트 갱신.
