# 웹 유형 → 교통 장면 출제 절차

> 문제은행 자문 · 2026-10-04
> 웹에서 모은 유형(`01-…`)을 우리 문제(템플릿)로 옮길 때 이 순서를 따른다. 기준은 CLAUDE.md, SPEC 2.1·4절, `docs/curriculum/07-line1-templates.md` 0.4절(검수 목록)·0.9절(힌트 규칙).

## 한 장 요약 (8단계)
| # | 할 일 | 통과 조건 |
|---|---|---|
| 1 | **구조로 줄이기**: 웹 문제를 "무엇을 주고 → 무엇을 묻나"(구조군 C·M·F·B·J·R·E·P·A, README 2.2절) 한 줄로 쓴다 | 원문 문장·숫자가 남아 있지 않다 |
| 2 | **자리 정하기**: 주 노드(핵심 아이디어), 단계(04 기준표 + 근거 축), 범위(원문 안/7+) | 1~6단계면 원문 해설 안. 주 노드가 우리 역이 아니면 그 역으로 보냄 |
| 3 | **수량 역할표**: 문제 속 수량마다 아래 넷 중 하나로 정한다 | 제원은 FACTS ✅ 값이거나 "~라고 해 봐요" |
| 4 | **장면 고르기**: 연산의 뜻에 맞는 장면을 2절 표에서 고른다 | 연산의 뜻(합병·첨가·제거·비교·등분·포함)이 장면과 같다 |
| 5 | **장소 맞추기**: 역 이름은 문제에서 실제로 쓰일 때만, 실제 장소 소재는 그 근처 역에만 | 0.4절 1·2번 |
| 6 | **숫자 고르기**: 현실적인 크기, 정답·판별 오답과 문제 속 수가 겹치지 않게(`reject`), 앞자리만 봐도 풀리는 수 피하기 | 0.4절 5·10번 |
| 7 | **문장 쓰기**: 4절 문체 규칙 | 1~4단계 두 줄 이내, 한 문장 한 뜻 |
| 8 | **오답·힌트·검증**: 웹의 흔한 오답 → 판별 오답 값, 힌트 ①~④(0.9절), 채점 함수 테스트·씨앗값 검사 | `tests/templates.test.js` 통과 |

억지 연결이 되면(장면이 연산의 뜻과 안 맞거나, 숫자가 비현실적) **교통 이야기를 붙이지 않고** 정비창 점검(식)이나 도전 문제(`challenge: true`)로 둔다. 장식용 역 이름보다 담백한 계산이 낫다.

## 1. 수량 역할표 (3단계의 핵심)
| 역할 | 무엇 | 꼬리표 | 문장 모양 |
|---|---|---|---|
| **사실** | FACTS.md ✅ 값(1호선 8량·40역·39.9km, 역 순서, 이용객 87만 3천 명, 부산 인구 등) | `n(v, { real: true, source })` | 단정해도 된다: "1호선은 8량이에요." |
| **그날의 상황** | 타고 내린 사람, 기다리는 단체, 그날 모은 승차권, 그날 잔액 | `n(v, { virtual: true })` | 첫머리에 "어느 날"(한 문제에 한 번). "~탔어요", "~있었어요" |
| **가정한 제원·규칙** | 좌석 수, 한 칸 정원, 엘리베이터 정원, 배차 간격, 역 사이 거리, 없는 급행 | `virtual` | "~라고 해 봐요", "만약 ~라면", "~하는 급행을 만들어 봐요". 단정 금지 |
| **순수 계산** | 식 속 수, 숫자 카드 | `n(v)` | 이야기 없음 |

- 웹 문제에 "버스 한 대에 45명이 탈 수 있어요"처럼 **제원이 들어 있으면** 둘 중 하나로 바꾼다: ① 그날의 상황으로 돌리기("어느 날 버스마다 45명씩 탔어요") ② 가정으로 밝히기("한 줄에 4자리라고 해 봐요"). 실제 값처럼 단정하지 않는다.
- 실제 값이 FACTS에 있는데 문제 숫자로 쓰기 어려우면(예: 1호선 좌석 수는 FACTS에 없음) 지어내지 말고 상황 숫자로 바꾼다.

## 3. 옮기기 예 (구조만, 숫자는 우리 것)
| 웹 유형(구조) | 교통 장면으로 | 수량 역할 |
|---|---|---|
| 어떤 수에서 빼야 할 것을 더했더니 □ → 바르게 계산하기 (N03, B, 4단계) | 교통카드 잔액을 계산기로 셈하다 두 숫자를 바꿔 눌렀어요 → 바른 잔액 | 잔액·금액 = 그날의 상황 |
| 몇씩 몇 묶음, 남는 것 → 거꾸로 전체 (N15, B, 4단계) | 어느 날 승객을 8명씩 모았더니 8묶음과 1명 → 7명씩이면 | 승객 = 상황 |
| 전체의 몇 분의 몇이 □ → 전체 (N17, B, 4단계) | 어느 날 한 칸 승객의 3/8인 21명이 내렸어요 → 처음 승객 | 승객 = 상황 |
| 어림해서 넘는지 판단 (N04, J·A, 2~3단계) | 열차에 더 탈 수 있는 사람과 기다리는 세 단체 | 더 탈 수 있는 수 = 그날의 상황(정원 단정 아님) |
| 자릿값 표 → 수 읽기 (N20, M, 1~3단계) | 2025년 지하철 하루 평균 이용객 87만 3천 명 | 사실(FACTS ✅) |

## 4. 문체 규칙 (문장 쓰기, 7단계)
`02-style-review-N01-N20.md` 1절의 공통 고침 규칙 14개를 따른다. 요약:
- "~해요"체, 한 문장에 한 가지 뜻. 묻는 문장은 하나("~은 몇 명이에요?"). 1~4단계는 약 60자(두 줄) 안.
- 교과서 용어를 쓴다(받아올림·받아내림, 몫·나머지, 나누어지는 수·나누는 수, 분모·분자, 진분수·가분수·대분수, 소수 한 자리 수, 자릿값, 세로셈, 수 모형, 어림하기, 검산, 비교하기). "빌려 와요", "올림", "나뉠 수", "견주다", "대충"은 쓰지 않는다.
- "나누다"는 ÷ 뜻으로만. 수를 쪼갤 때는 "갈라".
- 5~6학년 용어(이하·초과·미만, 올림·버림·반올림, 평균)와 괄호 없는 혼합 계산은 3~4학년 역 문장에 쓰지 않는다.
- 어른 말·한자어를 풀어 쓴다("총" → "모두", "각각" → "~마다"/"하나씩", "장부"·"탐방" → 아이 말).
- 철도 낱말: 첫 문장에서 "1호선 열차는 8칸이에요(8량)."로 한 번 풀고, 셈 대상은 "칸"만. "편성"·"상행/하행"은 문제에 쓰지 않거나 그림으로 보여준다.
- 이름표는 괄호: "(가) 단체". 피드백은 긍정 물음 하나.
- 숫자와 단위는 붙여 쓴다(3명, 0.7km). 한글 단위가 섞인 큰 수는 쉼표 없이 "3억 1877만", 숫자만이면 "318,770,000".
- 숫자·식 뒤 조사는 손으로 쓰지 말고 `jo()`/`ieyo()`로 붙인다.
