## 1. 전체 평가: 가장 큰 위험 3가지

| 순위 | 위험 | 왜 위험한가 | 대응 |
|---|---|---|---|
| **1** | **문제 화면 과밀** | 문제·그림·입력(7종)·연습장·힌트 4단계·🔊·신고·음 끄기·진행 표시가 한 화면에 모인다. 초3은 작업 기억이 작아서 화면 요소가 많으면 문제 문장보다 버튼을 먼저 본다. 서준 유형은 "글 대신 버튼 누르기"로 빠진다. 기획서에 문제 화면 배치가 아직 없다. MVP 전체가 이 화면 위에 있다. | **고정 영역 4개**(진행 띠 / 문제 / 입력 / 도구 막대)로 나누고 영역마다 할 일을 하나만 둔다(3.2절). 신고·음 끄기는 도구 막대 끝에 작게 둔다. 힌트는 오른쪽 서랍으로, 문제를 가리지 않는다. |
| **2** | **입력 방식 7종 + 연습장의 소근육·학습 부담** | 숫자, 분수, 경로 그리기, 칸 색칠, 시간표 칸, 원에 점 찍기, 숫자 카드가 문제마다 바뀐다. 입력법을 익히느라 수학에 쓸 인지 자원이 줄어든다. 끌기(드래그)는 초3에게 실패율이 높다. 잘못 눌러서 틀리면 "억울한 오답"이 되고, 하린 유형에게는 치명적이다. | **모든 입력을 "톡-톡"(두 번 누르기)으로 할 수 있게** 한다. 끌기는 보조로만 둔다. 입력 유형마다 처음 한 번은 시승 운행 안에서 10초짜리 시범을 보인다. **오답 처리 전 '확인' 단계**를 따로 둔다(6절). |
| **3** | **보상 연출이 운행 흐름을 끊음 + 노선 색과 피드백 색 충돌** | 정답마다 차량 이동, 역 개통, 소리, 도장이 나오면 6문제 동안 연출이 10번 넘게 끼어든다. 하린 유형은 기다리기를 싫어하고, 서준 유형은 연출만 보고 넘긴다. 또 부산 노선 색에 주황·초록·파랑 계열이 쓰인다면(확인 필요) 흔한 "초록=정답, 주황/빨강=오답" 관습과 겹친다. 그러면 1호선 화면에서 오답 표시가 노선 색처럼 보이거나 그 반대가 된다. | 운행 중에는 **진행 띠 위의 작은 이동(0.6초)** 만 보여준다. 큰 연출(노선도 점등, 개통 안내 방송, 카드)은 **운행 일지에서 한 번에 하나만** 보여준다. **피드백에는 색을 쓰지 않는다.** 정답은 ✓ 모양과 문구로, 오답은 회색 '정차' 표시와 문구로 알린다. 노선 색은 노선을 나타낼 때만 쓴다. |

그다음으로 볼 위험(4~5위)
- 4. **읽기 부담**: 초3 독해 편차가 크다. 🔊만으로는 부족하다. 읽는 부분을 강조해 주고, 숫자와 단위를 굵게 쓰고, 한 화면 두 줄 원칙을 화면 규격으로 강제해야 한다(4절).
- 5. **힌트 ② 열기 관문**("어디까지 해 봤어?")이 마찰을 만든다. 선택지는 3개 칩을 한 번 누르는 것으로 끝내야 한다. 식 입력을 하라고 하면 초3은 포기한다. 식 입력은 선택으로만 둔다.

## 2. 화면 목록과 흐름 (정보 구조)

### 2.1 제안 화면 목록

```
[첫 실행만] 별명·차량 색 고르기 ─┐
                                 ▼
┌──────────── 노선도 홈 (허브) ────────────┐
│  출발(보통 운행) / 도전 운행 / 차고 / [부모] │
└───┬───────────┬───────────┬──────────────┘
    ▼           ▼           ▼
 운행 화면     차고        부모 화면(PIN)
 (문제 화면)   ├ 내 차량·꾸미기
    │         ├ 카드첩(열차/버스/특별) → 카드 상세(앞·뒤) → 이미지 저장
    │         └ 운행 달력(주간 목표 켰을 때만)
    ▼
 문제 뒤 시트: 왜 그런지 / 다른 풀이 보기
    ▼
 운행 일지 ── 임시 정차 목록(시트) ── 한 번 더 운행 / 홈으로
```

같은 운행 화면 틀을 다시 쓰는 모드: **시승 운행**(배치고사), **운행 면허 시험**, **정비 운행**, **회복 운행**. 머리 띠의 이름과 진행 표시만 바뀐다.

### 2.2 빠진 화면 (기획서에 없음 → 추가 필요)
| 화면 | 이유 |
|---|---|
| **이어서 출발** 카드 (홈 위 시트) | "○○역 정차 중" 저장이 있으면 홈에서 바로 보여야 한다. 없으면 아이는 새 운행을 시작하고 저장이 묻힌다. |
| **문제 뒤 해설 시트** | "왜 그런지 / 다른 풀이 보기"를 둘 자리가 정의되지 않았다. 문제 화면 아래에서 올라오는 시트로 한다. |
| **신고 시트** | 버튼만 있고 흐름이 없다. 이유 칩 4개(숫자가 이상해요 / 부산 사실이 틀려요 / 그림이 이상해요 / 기타) + 선택 메모 + "보냈어요(기기에 저장)". |
| **면허 시험 시작·결과 화면** | 합격(차고 출고 연출) / "정비가 필요해요" 두 갈래와 해설 다섯 개 목록. |
| **설정(음·읽어주기)** | 아이가 바꿀 수 있는 것: 음 끄기, 🔊 자동 재생. 나머지는 부모 화면에 둔다. |
| **입력 시범(코치 표시)** | 입력 유형마다 처음 한 번만 나오는 손가락 시범. 화면이라기보다 겹쳐 보이는 층이다. |
| **백업 실패·저장 공간 오류 안내** | localStorage 실패 시 아이가 아니라 부모 화면에 안내한다. 아이 화면에는 표시하지 않는다. |

### 2.3 합칠 화면
- **차고 + 카드첩 + 꾸미기 → "차고" 하나**에 탭 3개(차량 / 카드 / 꾸미기). 도윤의 "쌓이는 것이 많다"에 대한 구조적 답이다. 보상은 홈과 일지에서 차고로 들어가는 입구 하나로 모은다.
- **틀린 문제 다시 보기 = 일지의 "다음 운행 임시 정차: N곳" 시트.** 따로 메뉴를 두지 않는다(서준: 숙제 같음).
- **시승 운행 결과 = 첫 운행 일지.** 결과 화면을 따로 만들지 않고, 일지의 "가장 큰 소식" 자리에 "시작 차량: 급행버스"를 보여준다.
- 노선도와 실제 지도 겹쳐 보기는 별도 화면이 아니라 **노선도 홈의 보기 전환 토글**로 둔다(개통 후).

### 2.4 형제 앱과의 일관성
- [부모] 버튼 위치(오른쪽 위), 시스템 한글 글꼴, 지형 색(육지 `#EDF1EC`, 바다 `#B9D4E6`, 글자 `#1F3342`), "강조색 = 노선의 공식 색", "색만으로 뜻을 전하지 않는다(노선에 번호)", '동작 줄이기' 대응을 **그대로 가져온다**.
- 형제 앱의 "기억에 남는 한 가지 = 하루 운행 장면, 나머지는 조용히" 원칙을 이 앱에도 적용한다. 이 앱의 "한 가지"는 **운행 일지의 역 개통 장면**이다.
- 노선도 그리기 컴포넌트(역 점, 노선 선 굵기, 역 이름 서체)는 두 앱이 같은 모양이어야 한다. 아이는 같은 부산 지도를 두 앱에서 다르게 보면 바로 알아챈다.

## 3. 핵심 화면 와이어프레임 (태블릿 가로, 약 1280×800 기준)

### 3.1 ① 노선도 홈
```
┌──────────────────────────────────────────────────────────────────┐
│ 도윤 차고 ▸                               🔊  ⚙         [부모] │ ← 56px 상단 띠
├──────────────────────────────────────────────────────────────────┤
│                                                                  │
│      (부산 노선도: 켜진 역 = 노선 색 채운 원 + 굵은 역 이름,         │
│                  꺼진 역 = 회색 빈 원 + 보통 굵기 이름)              │
│                                                                  │
│            ①━━●━━●━━●━━◉🚌━━○━━○━━○                              │
│                     서면  ↑내 차량  양정   시청                    │
│                                                                  │
│   [노선도 ⇄ 실제 지도] (개통 후에만 보임)          누적 48 km      │
├──────────────────────────────────────────────────────────────────┤
│  ┌ 이어서 출발 ──────────────┐                                    │
│  │ 1호선 양정역 정차 중  [이어서]│   (저장이 있을 때만. 없으면 ↓)      │
│  └───────────────────────────┘                                   │
│  다음 역: 시청 — 큰 수 · 2문제 남음                                 │
│  [      출발      ]   [ 도전 운행 ]   ← 출발은 크게(가로 320, 높이 72)│
└──────────────────────────────────────────────────────────────────┘
```
- 노선도가 화면의 60% 이상을 차지한다. 첫 화면에는 내 차량을 중심으로 한 확대 상태를 보여주고, 두 손가락 확대·축소와 "전체 보기" 버튼을 둔다.
- 노선 선택: 노선 번호 원(①②③④동해)을 누르면 그 노선의 "다음 역"이 바뀐다. 노선 이름은 "계산 노선"처럼 번호 옆에 작게 쓴다.
- 홈에 보이는 수치는 **km 하나뿐**이다. 도장·카드 진행은 차고 안에 둔다.
- 도전 운행 버튼은 7단계 미만이거나 해당 노선에서 처음 운행할 때 숨기지 않고 보여주되, 보조 버튼 모양(외곽선)으로 둔다.

### 3.2 ② 문제 화면 (운행 화면)
```
┌──────────────────────────────────────────────────────────────────┐
│ ✕ 그만   ①━●━●━◉🚌━○━○   서면 → 양정 · 다음 역까지 2문제    🔊 🔇 │ ← A. 진행 띠 (56px)
├─────────────────────────────────────────┬────────────────────────┤
│ B. 문제 영역 (왼쪽 60%)                  │ C. 입력 영역 (오른쪽 40%) │
│                                         │                        │
│  노포역에서 6시 12분에 출발해요.          │   ┌────┐시 ┌────┐분    │
│  1시간 18분 뒤 도착하는 시각은?           │   │  7 │   │ 3_ │       │
│   (문장 최대 2줄, 24px, 숫자 굵게)        │   └────┘   └────┘       │
│                                         │                        │
│  ┌───────────────────────────────┐      │   ┌───┬───┬───┐        │
│  │                               │      │   │ 1 │ 2 │ 3 │        │
│  │    그림 / 노선도 조각 / 시간표   │      │   ├───┼───┼───┤        │
│  │   (연습장을 켜면 이 위에 그림)   │      │   │ 4 │ 5 │ 6 │  키 64px│
│  │                               │      │   ├───┼───┼───┤        │
│  └───────────────────────────────┘      │   │ 7 │ 8 │ 9 │        │
│                                         │   ├───┼───┼───┤        │
│                                         │   │ ⌫ │ 0 │ , │        │
│                                         │   └───┴───┴───┘        │
│                                         │  [   답 내기   ] 72px   │
├─────────────────────────────────────────┴────────────────────────┤
│ D. 도구 막대   ✏ 연습장    💡 힌트(①)                  ⚑ 이상해요  │ ← 64px
└──────────────────────────────────────────────────────────────────┘
```
배치 원칙
- **A 진행 띠**: 그 운행에서 지나는 역만 보여주는 띠 노선도. 차량은 여기에서만 움직인다. 전체 노선도는 운행 중에 띄우지 않는다.
- **B 문제**: 문장 → 그림 순서로 둔다. 그림은 문장이 가리키는 것만 그린다. 🔊를 누르면 읽는 어절을 밑줄로 따라간다.
- **C 입력**: 오른손잡이 기준 오른쪽. 부모 화면에서 "왼손 배치"로 좌우를 바꿀 수 있다. **'답 내기'는 ⌫에서 멀리**, 키패드 아래 전체 폭에 둔다.
- **D 도구**: 연습장, 힌트, 신고만 둔다. 신고(⚑)는 오른쪽 끝, 아이콘+글자 작게. 실수로 눌러도 시트가 열릴 뿐 아무 일도 일어나지 않는다.
- 음 끄기(🔇)는 SPEC 대로 "늘 보이는 자리"인 진행 띠 오른쪽에 둔다(모든 화면에서 같은 자리).
- "✕ 그만"을 누르면 "양정역에 정차할까요? 다음에 이 문제부터 해요" 확인을 거친다. 실수로 나가지 않게 하고, 정차 저장이 벌이 아님을 알린다.
- 연습장이 켜지면 B의 그림 위에 반투명 그리기 층이 생기고, 도구 막대가 [펜 굵게/가늘게][지우개][전부 지우기][연습장 끄기]로 바뀐다. 따로 빈 종이를 원하면 "빈 종이" 탭으로 B 전체를 덮는다(학생 질문 4번 참고).

**정답 뒤 상태**
```
│  ✓ 양정역까지 왔어요                    (✓ 아이콘 + 문장, 색 강조 없음)  │
│  [왜 그런지]  [다른 풀이 보기]                      [ 다음 역으로 ▶ ]  │
```
- 진행 띠의 차량만 0.6초 동안 한 칸 이동하고 짧은 효과음을 낸다. 다음 문제는 **아이가 눌러야** 나온다(자동 진행 금지 원칙을 운행 안에도 적용).

**오답 뒤 상태**
```
│  ⏸ 버스가 잠깐 멈췄어요. 다시 출발해 볼까요?                         │
│  (맞춤 피드백이 있으면 한 줄 더) "남은 8명은 어디 타요?"                │
│  입력한 답은 그대로 남아 있음 → 고쳐서 다시 [답 내기]                    │
```

### 3.3 ③ 힌트 펼침 (오른쪽 서랍, C 영역을 덮음)
```
┌─────────────────────────────────────────┬────────────────────────┐
│ (문제 영역은 그대로 보임)                 │ 💡 힌트          [닫기 ✕]│
│                                         │                        │
│                                         │ ① 노선 확인       [펼침] │
│                                         │  "출발 6시 12분,        │
│                                         │   걸린 시간 1시간 18분"   │
│                                         │ ─────────────────────── │
│                                         │ ② 경로 안내       🔒     │
│                                         │  어디까지 해 봤어요?     │
│                                         │  [식 세우기][첫 계산]    │
│                                         │  [잘 모르겠어요]         │
│                                         │  (식 한 줄 쓰기 ▸ 선택)   │
│                                         │ ─────────────────────── │
│                                         │ ③ 중간 정류장     🔒     │
│                                         │ ④ 종착역 직전     🔒     │
│                                         │   "④를 보면 쌍둥이 문제로 │
│                                         │    회복 운행을 해요"      │
│                                         │                        │
│                                         │ [ 입력으로 돌아가기 ]     │
└─────────────────────────────────────────┴────────────────────────┘
```
- 서랍은 문제 문장과 그림을 가리지 않는다. 힌트를 보면서 문제를 다시 읽을 수 있어야 한다.
- 단계는 위에서 아래로 쌓이는 아코디언 방식이다. 이미 연 단계는 접어도 다시 펼 수 있다.
- ④를 열기 전에 결과("회복 운행")를 미리 알려준다. 숨긴 규칙이 없어야 한다(하린).
- "힌트 버튼이 눈에 띄게 바뀐다"(2번 오답 / 오래 멈춤): 💡 버튼 테두리가 한 번(1.2초) 부드럽게 빛나고, 글자가 "힌트 볼까요?"로 바뀐다. **계속 깜박이지 않는다.** 오래 멈춤의 기준은 90초 정도로, 아이에게 보이지 않게 둔다.
- 힌트 ②의 교차로 숫자 적기처럼 **화면이 바뀌는 비계**는 서랍이 아니라 B 영역의 그림 자체를 바꾼다. 서랍에는 "그림에 숫자를 적어 보세요" 안내만 둔다.

### 3.4 ④ 운행 일지 (다섯 줄 이내)
```
┌──────────────────────────────────────────────────────────────────┐
│            1호선  서면 → 양정                                      │ ← 제목 = 실제 도착 역
│                                                                  │
│   ┌──────────────────────────────────────────────────────────┐   │
│   │   (가장 큰 소식: 노선도 조각에서 부전·양정 역이 차례로 켜짐)     │   │ ← 화면 높이 45%
│   │            "양정역 개통!"  + 안내 방송 1회                    │   │
│   └──────────────────────────────────────────────────────────┘   │
│                                                                  │
│  1  새로 켜진 역   부전 · 양정                                     │
│  2  금 도장 +3     [카드 그림] 무궁화호 ■■■□□ 3/5                  │ ← 작게
│  3  누적 48 km · 차고 꾸미기까지 2 km!                              │ ← 크게
│  4  다음 운행 임시 정차: 2곳 ▸                                     │ ← 누르면 시트
│  5  다음 역: 시청 — 큰 수                                          │
│                                                                  │
│      끝까지 운행 완료!        [ 홈으로 ]   [ 한 번 더 운행 ]         │
└──────────────────────────────────────────────────────────────────┘
```
- "가장 큰 소식" 우선순위(한 운행에 하나만): **승급 > 새 카드 > 환승역 개통 > 일반 역 개통 > km 이정표("대구만큼") > 금테 완성**. 나머지 소식은 아래 다섯 줄에 글로만 나온다.
- 큰 소식 연출은 처음 2초가 지나면 아무 곳이나 눌러 건너뛸 수 있다.
- 새로 켜진 역이 없으면(쉬운 문제만 끼운 운행 등) 큰 소식 자리에 "양정역에 정차했어요"와 진행 띠만 작게 보여준다. 빈 자리를 억지 칭찬으로 채우지 않는다.
- [홈으로]와 [한 번 더 운행]은 같은 크기로 둔다. 한 번 더 운행을 크게 키우면 "자동 이어가기"의 시각적 변형이 된다.

### 3.5 ⑤ 열차 카드 앞·뒷면 (세로형, 실물 카드 비율 63:88)
```
 앞면                                뒷면
┌──────────────────────────┐       ┌──────────────────────────┐
│ ⑦  무궁화호       ★금테  │       │ ⑦ 무궁화호 · 카드 문제      │
│ ┌──────────────────────┐ │       │                          │
│ │                      │ │       │ "최고속도로 2시간 달리면     │
│ │   (실제와 닮은 측면도)  │ │       │  몇 km를 갈 수 있을까요?"   │
│ │                      │ │       │  (앞면의 제원을 써요)        │
│ └──────────────────────┘ │       │                          │
│ 최고속도   ○○○ km/h      │       │  [ 앞면 보기 ↺ ]            │
│ 량 수      ○량            │       │  [ 풀어 보기 ]              │
│ 좌석 수    ○○○석          │       │                          │
│ 운행 구간  ○○ – ○○        │       │  금 도장 ■■■□□ 3/5          │
│ 처음 달린 해  ○○○○년        │       │  금테까지 2개 더             │
│ 제작사     ○○             │       │                          │
│ ─────────────────────── │       │                          │
│ 출처: ○○ (작게, 11pt)      │       │        [ 이미지로 저장 ]     │
└──────────────────────────┘       └──────────────────────────┘
```
- 제원 숫자는 모두 **확인 필요**(부록 A 검증 후 채움). 확인 못 한 칸은 "—"로 비우고 가짜 값을 넣지 않는다.
- 금테는 테두리 굵기와 ★ 표시를 함께 써서 색만으로 구분하지 않는다.
- 뒤집기는 카드를 누르거나 [앞면 보기] 버튼으로 한다. 회전 연출은 0.4초, 동작 줄이기 설정이면 바로 바뀐다.
- 이미지 저장본에는 별명·날짜·차고 이름을 넣지 않는다(SPEC 3.8).
- 버스 카드도 같은 틀을 쓰고 제원 항목만 바꾼다. 위쪽 원 안에 노선 번호, "기준 연도 ○○○○년"은 출처 옆에 둔다.

## 5. 보상·피드백 연출의 시각적 위계

### 5.1 세 층으로 나누기
| 층 | 무엇 | 어디서 | 얼마나 |
|---|---|---|---|
| **1층 (주인공)** | 노선도 점등, 내 차량 이동 | 홈 노선도, 일지의 큰 소식 자리 | 화면의 가장 큰 면적, 유일하게 움직이는 큰 그림 |
| **2층 (숫자 하나)** | 누적 km | 홈 오른쪽 아래, 일지 3번째 줄 | 큰 숫자 하나. 운행 중에는 보이지 않음 |
| **3층 (모음)** | 금 도장, 금테 진행, 카드, 정비 완료, 꾸미기 | 차고 안, 일지 2번째 줄(작게) | 글자 크기 16~18px, 작은 카드 그림. 큰 소식 자리에는 "새 카드"나 "승급"일 때만 올라옴 |

원칙
- **운행 중(문제 화면)에는 1층의 작은 판(진행 띠 이동)만 보인다.** 도장 수, km, 카드 진행은 문제 화면에 없다. 서준 유형이 숫자를 세느라 문제를 대충 푸는 것을 막는다.
- **한 순간에 움직이는 것은 하나뿐**이다. 일지에서 역 점등이 끝난 뒤에야 아래 줄이 나타난다(위에서 아래로 0.15초 간격, 총 1초 이내).
- 금 도장은 문제 화면에서 받는 순간 진행 띠의 해당 역 점 옆에 작은 ✦ 표시(12px)만 붙고, 개수는 일지에서 센다.
- "회송 운행"(절반 km)은 일지 3번째 줄에 "회송 +3 km"로 사실만 쓴다. 벌처럼 보이지 않게 회색 글자를 쓰지 않는다.

### 5.2 오답 피드백 "버스가 잠깐 멈췄어요"
1. **0~0.3초**: 진행 띠의 차량이 앞으로 살짝 기울었다가 제자리로 온다(브레이크 느낌, 4px). 동작 줄이기면 생략.
2. 입력 칸 테두리가 중립 회색 점선으로 바뀌고, 그 위에 ⏸ 아이콘과 문구가 나온다. **빨강·흔들기·소리 없음**(아주 작은 '칙' 공기 빠지는 소리 정도는 학생에게 확인 → 7절 질문 3).
3. **입력한 답은 지우지 않는다.** 어디를 고칠지 아이가 직접 판단하게 한다. 입력 칸을 다시 누르면 문구가 사라지고 편집 상태가 된다.
4. 맞춤 피드백(예: 5대 → "남은 8명은 어디 타요?")이 있으면 문구 아래 한 줄로 붙인다. **오답 숫자를 크게 반복하지 않는다.**
5. 두 번째 오답: 같은 연출 + 💡 버튼이 한 번 빛남(3.3절). 쉬운 문제를 끼울 때는 "잠깐 쉬어 가는 정류장이에요"처럼 이유를 짧게 말한다(꼼수 방지 규칙상 진행이 없다는 것도 숨기지 않는다).
6. 객관식이 한 번 틀린 뒤 직접 입력으로 바뀔 때: 선택지가 접히며 키패드가 나온다. 문구는 "이번엔 직접 써 볼까요?" — 벌이 아니라 방식 변경으로 보이게.

## 6. 입력 방식 설계 (초3 소근육 기준)

공통 규칙
- **모든 입력은 '답 내기'를 눌러야 채점한다.** 칸을 다 채웠다고 자동 채점하지 않는다(실수 입력 = 억울한 오답 방지).
- **되돌리기(↶)를 모든 그리기·색칠·카드 입력에 둔다.** 전부 지우기는 확인을 거친다.
- 시스템 키보드는 쓰지 않는다(화면을 가리고 기기마다 다르다). 모든 숫자 입력은 앱 키패드로 한다.
- 입력 유형별 첫 등장 때 10초 손가락 시범(겹침 층, 한 번만, 건너뛰기 가능).
- 끌기와 톡-톡을 **둘 다** 받는다. 판정은 손을 뗀 위치 기준.

| 입력 | 설계 | 초3 주의점 |
|---|---|---|
| **숫자 키패드** | 3×4 전화기 배열(1이 왼쪽 위), 키 64px, ⌫는 왼쪽 아래, 답 내기는 아래 전체 폭. 단위(분, km, 명)는 입력 칸 오른쪽에 고정 글자로 | 계산기 배열(7이 위)과 헷갈림 → 전화기 배열로 통일. 큰 수는 쉼표 자동 삽입. 칸이 여러 개(시·분)면 누른 칸이 굵은 테로 표시되고, 첫 칸이 다 차면 다음 칸으로 자동 이동하되 되돌아갈 수 있음. |
| **분수 입력** | 위·아래 두 칸이 가로선으로 이어진 틀. 처음엔 **분모(아래)** 칸이 아니라 **분자(위)** 칸에 커서. 칸을 직접 눌러 바꿀 수 있음. 대분수(5학년~)는 왼쪽에 자연수 칸 추가 | 3학년은 "/" 입력을 모른다. 틀 모양이 교과서 표기와 같아야 한다. 약분 여부는 채점에서 문제별로 정함(정답 문구에 "기약분수로" 같은 조건이 없으면 같은 값 인정). |
| **경로 그리기** | 격자 교차점(지름 20px 점, 판정 반경 28px)을 **차례로 톡-톡** 누르면 선이 이어짐. 끌기도 가능. 대각선·건너뛰기는 받지 않음(점이 흔들리며 안 붙음). 한 칸씩 ↶ | 손가락 끌기는 손이 그림을 가린다. 선 굵기 6px 이상, 그린 경로는 노선 색이 아니라 중립 진한 색. 완성된 경로는 목록 칩(경로 1, 2…)으로 남겨 몇 개 찾았는지 셀 수 있게(서준: 하나 빠뜨림). 같은 경로를 두 번 그리면 "이미 찾은 길이에요". |
| **칸 색칠** | 칸 하나 누르면 칠해짐/다시 누르면 지워짐. 칸 56px 이상. 끌어서 여러 칸 칠하기는 보조 | 칠한 칸 수를 화면에 세어 보여주지 않는다(개념 확인이 목적). 칠한 색과 빈 칸은 무늬(빗금)로도 구분. |
| **시간표 칸** | 칸을 누르면 키패드가 그 칸에 연결. 한 칸을 채우면 다음 칸으로 자동 이동. 처음 두 칸은 예시로 채워져 있음(회색 글씨) | 칸이 많으면 한 줄에 4~5칸까지만, 넘치면 다음 줄. "칸을 다 채워야 선택지가 열림"은 남은 칸 수를 작게 표시해 막힌 이유를 알게 한다. |
| **원에 점 찍기** | 원 둘레에 눈금(정류장 후보)을 두고 그 눈금에만 붙음. 옛 정류장 = 채운 원, 새 정류장 = 빈 사각형(색 + 모양) | 자유 위치에 찍게 하면 손떨림이 오답이 된다. 순환 문제의 핵심은 "몇 개"이지 정밀한 위치가 아님. |
| **자리 카드(숫자 카드)** | 카드를 **눌러 고른 뒤 자리 칸을 누르면** 들어감. 끌기도 가능. 자리 칸 위에 "만·천·백·십·일" 이름 | 카드 64px, 자리 칸 72px. 이미 들어간 카드를 누르면 카드 줄로 돌아감. |
| **연습장** | 펜 2굵기, 지우개, 전부 지우기, ↶. 손바닥 오입력 대비: 펜(`pointerType: pen`)이 감지되면 손가락 그리기를 끔 | 연습장 그림은 채점에 쓰지 않고, 문제를 넘기면 지워짐(부모 화면에도 저장하지 않음 — 저장한다면 아이에게 알릴 것). "연습장에 그렸으면 안내 생략" 판정은 선 길이 일정 이상으로. |

## 7. 학생 세션에 물어볼 질문 (5개)

1. **운행 중 노선도**: 문제 화면 맨 위에 "지금 지나는 역만 나오는 띠"가 있고 버스가 한 칸씩 움직여요. 큰 노선도는 운행이 끝나고 일지에서 불이 켜지는 걸 봐요. vs 문제 화면 구석에 큰 노선도가 작게 늘 있어요. 어느 쪽이 더 좋아요? 문제 풀 때 방해되는 쪽은?
2. **틀렸을 때 내 답**: 틀리면 ㉮ 내가 쓴 답이 그대로 남아 있어서 고칠 수 있어요 ㉯ 답이 지워지고 처음부터 다시 써요. 어느 쪽이 좋아요? 그리고 틀렸을 때 아주 작은 소리(버스 브레이크 '칙')가 나는 건 괜찮아요, 아니면 소리가 아예 없는 게 나아요?
3. **역 개통 장면 길이**: 운행이 끝나면 역에 불이 켜지고 "이번 역은 양정역입니다" 방송이 나와요(2초쯤). 매번 보고 싶어요, 처음 몇 번만 길게 보고 그다음엔 짧게가 좋아요, 아니면 건너뛰기 버튼만 있으면 돼요?
4. **연습장**: ㉮ 문제 그림 위에 바로 그리기 ㉯ 옆에 빈 종이를 펴서 그리기. 어느 쪽을 더 쓸 것 같아요? (하린에게는 추가로: 연습장에 그린 게 운행이 끝나면 사라져도 괜찮아요?)
5. **길 그리기 문제**: 바둑판 길을 그릴 때 ㉮ 손가락을 떼지 않고 쭉 끌기 ㉯ 교차로 점을 하나씩 톡톡 누르기. 어느 쪽이 편해요? 찾은 길이 "길 1, 길 2…"로 옆에 쌓이면 도움이 돼요, 아니면 답이 보이는 것 같아요?
