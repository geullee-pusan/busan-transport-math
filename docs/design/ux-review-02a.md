# UX 자문 2차 보충 — 역사 카드 금테, 배지 글자

> 작성: UX 자문, 2026-10-04. `ux-review-02.md`의 4.4절과 1.2절을 보충한다(결정 회신 ②③ 반영).

## 1. 역사 카드 + 금테 테두리

다섯 종류가 **선 모양만으로** 구분되어야 한다(흑백에서도).

| 종류 | 테두리 | 표시 |
|---|---|---|
| 아직 못 얻은 카드 | 점선 1px | 실루엣 + 얻는 조건 |
| 일반 | 단선 1.5px | — |
| 금테 | 굵은 단선 4px + ★ | `금테 완성` |
| 역사 | 가는 이중선(1px + 2px 틈 + 1px) | 맨 위 `운행 기록 2016.12–2026.8` 띠 |
| **역사 + 금테** | **바깥 굵은 선 4px + 안쪽 가는 선 1px**(2px 틈) + ★ | 맨 위 띠 유지, ★는 띠 오른쪽 끝 |

```
 ┏━━━━━━━━━━━━━━━━━━━━━━━━━━┓   ← 바깥 4px (금테)
 ┃┌────────────────────────┐┃   ← 안쪽 1px (역사)
 ┃│ 운행 기록 2016.12–2026.8 ★│┃
 ┃│ (SRT 그림, 컬러)          │┃
 ┃│ …제원(과거형)…            │┃
 ┃└────────────────────────┘┃
 ┗━━━━━━━━━━━━━━━━━━━━━━━━━━┛
```
- 금테가 되는 순간의 연출은 일반 금테와 같다(바깥선만 굵어짐 + ★). 이중선의 안쪽 선은 그대로 남아 "역사"임이 유지된다.
- 금 도장 진행 막대는 역사 카드도 같은 위치(앞면 아래)에 둔다.

## 2. 배지 글자 `BGL` · `동해`

형제 앱 `lines.json`의 label을 따른다. 다만 원형 32px 배지에 세 글자는 들어가지 않으므로 **배지 모양 규칙**을 둔다.

| 글자 수 | 배지 모양 | 크기 | 글자 |
|---|---|---|---|
| 1자 (1·2·3·4) | 원 | 지름 32px | 굵게 20px |
| 2자 이상 (`동해`, `BGL`) | 캡슐(양끝 둥근 사각) | 높이 32px, 좌우 여백 8px | 굵게 16px — 큰 글자 기준 미달이므로 **흰 글자 대비 4.5 이상 필요**: 경전철 흰 글자 4.93 ✓, 동해선 흰 글자 5.98 ✓ |

- 캡슐 배지는 환승역 캡슐 점(역 표시)과 헷갈리지 않게 **늘 노선 색으로 채우고** 글자를 넣는다(환승역 점은 흰 속).
- 형제 앱의 배지 모양도 같은지 확인 필요(다르면 형제 앱 쪽 모양을 따른다).
- `BGL`은 초3에게 뜻이 없는 영문 약자다. 배지 옆에 늘 `김해경전철`처럼 이름을 함께 쓰고, 🔊 읽어주기는 "비지엘"이 아니라 "부산김해경전철"로 읽게 검수 목록에 넣는다.
