# UX 자문 9차 — 처음 설정의 "부모님 단계"와 번호 없이 쓰던 기기

> 작성: UX 자문, 2026-10-04 · 요청: 아동 심리 04 R1(부모 번호 구멍) · 결정 반영: 밤 운행 시간 제한 없음(보호자 결정)
> 기준 기기 1480×924 / 924×1480. 배치는 ux-review-08의 첫 화면안(꺼진 노선도 + 이름 칸)으로 이어진다.

## 0. 전제 — 이 번호가 막을 수 있는 것과 없는 것
- 앱은 인터넷 없이 기기 하나에서만 돈다. **번호는 "부드러운 문"** 이다. 아이가 처음 설정을 혼자 하면 번호도 아이가 정할 수 있고, 이건 화면으로 완전히 막을 수 없다.
- 그래서 목표를 셋으로 둔다.
  1. **보통의 흐름**에서는 부모가 먼저 정하게 한다(처음 설정 맨 앞).
  2. 아이가 정했다면 **부모가 알아챌 수 있게** 한다(정한 날짜·시각을 보여 줌).
  3. 부모가 번호를 잊거나 아이가 정해 버렸을 때 **진행을 잃지 않고 되찾는 길**을 둔다(복구 번호).
- 수학 문제로 부모를 확인하는 방식은 쓰지 않는다(아동 심리 H3: 아이가 풀 수 있음).

## 1. 처음 설정 흐름 (새 기기)
```
[1 부모님 단계 ①]  →  [2 부모님 단계 ②]  →  [3 건네주기]  →  [4 아이 첫 화면(08 4.1)]  →  시승 운행
 번호 4자리 두 번       하루 운행 수            "아이에게 건네주세요"   꺼진 노선도 + 이름 + 차량
 + 복구 번호 받기
```
- 모두 **세 화면**으로 끝낸다(부모가 기기를 들고 서서 하는 일이라 짧게).
- 부모님 단계 화면은 **어른용 화면 모양**: 지도·차량 그림 없음, 크림 바탕, 왼쪽 정렬 글 18~20px, 단추 72. 아이 화면과 한눈에 달라 보여야 아이가 "내 화면이 아니다"를 안다.

### 1.1 부모님 단계 ① — 번호
```
┌──────────────────────────────────────────────────────────────────────┐
│  부모님이 먼저 해 주세요 (1/2)                                          │
│                                                                      │
│  ┌ 왼쪽 (글) ───────────────────────┐  ┌ 오른쪽 (입력) ──────────────┐ │
│  │ 부모님 번호 4자리를 정해 주세요.     │  │  ● ● ○ ○   (가린 칸 4개)     │ │
│  │ 이 번호로                          │  │                             │ │
│  │ · 부모 화면을 열고                  │  │  1  2  3                    │ │
│  │ · 운행 중에 "이번 운행 끝나면 쉬기"를 │  │  4  5  6   (키 120×84)       │ │
│  │   걸 수 있어요.                     │  │  7  8  9                    │ │
│  │ 아이가 모르는 번호로 정해 주세요.     │  │     0  ⌫                    │ │
│  │ (생일·1234 같은 번호는 피해 주세요)   │  │                             │ │
│  └──────────────────────────────────┘  │  한 번 더 넣어 주세요 → 확인  │ │
│                                        └─────────────────────────────┘ │
└──────────────────────────────────────────────────────────────────────┘
```
- 앱 안 키패드(시스템 키보드 아님), 넣은 숫자는 ●로 가림. 두 번 넣어 확인.
- `1234`, `0000`, 같은 숫자 4개, 연속 숫자는 "아이가 맞히기 쉬운 번호예요. 다른 번호를 권해요"를 한 줄 보이되 **막지는 않는다**(부모 판단).
- 두 번째가 다르면 "두 번이 달라요. 처음부터 넣어 주세요."

**복구 번호** — 번호를 정한 바로 뒤, 같은 화면 오른쪽에:
```
  번호를 잊었을 때 쓰는 복구 번호예요. 적어 두거나 사진을 찍어 두세요.
        [ 4821 - 7730 ]   (8자리, 크게)
  [ 적어 뒀어요 ]
```
- 앱이 무작위로 만든 8자리. 이 기기에만 저장되고 어디로도 보내지 않는다.
- 부모 화면(번호로 연 뒤)에서 언제든 다시 볼 수 있다.

### 1.2 부모님 단계 ② — 하루 운행 수
```
  하루에 몇 번 운행할까요? (한 번에 약 10분)
  [1번] [2번 ✓] [3번] [4번]
  마지막 운행을 시작할 때만 "오늘의 막차예요"라고 알려요. 못 한 운행은 다음 날로 쌓이지 않아요.
  나중에 부모 화면에서 바꿀 수 있어요.
                                        [ 다음 ]
```
- 기본 2번이 미리 골라져 있다(그냥 다음을 눌러도 됨).
- 소리·읽어 주기 기본값은 여기서 묻지 않는다(설정이 늘면 부모가 서서 하기 힘듦. 기본값 그대로, 부모 화면에서 바꿈).

### 1.3 건네주기
```
┌──────────────────────────────────────────────────────────────────────┐
│                     아이에게 건네주세요                                  │
│                                                                      │
│   아이와 같이 읽어 주세요:                                              │
│   "부모님도 이 앱을 볼 수 있어. 어떤 역을 켰는지, 어디가 어려웠는지 봐.    │
│    같이 이야기하려고 보는 거야. 맞힌 개수로 혼내려는 게 아니야."          │
│                                                                      │
│              [ 아이에게 건네줬어요 ▷ ]  (88, 아이 화면 모양으로 바뀜)      │
└──────────────────────────────────────────────────────────────────────┘
```
- 지금 아이 첫 화면에 있는 "부모님도 이 앱을 볼 수 있어요" 안내 상자를 **여기로 옮긴다.** 부모가 직접 말해 주는 편이 아이에게 더 믿을 만하다(아동 심리 3차: 몰래 보는 것보다 미리 알리는 것). 아이 첫 화면은 그만큼 가벼워진다.
- 이 단추를 누른 뒤부터는 아이 화면이다. **뒤로 가기로 부모님 단계에 돌아갈 수 없다**(돌아가려면 부모 화면 → 번호).

### 1.4 아이 첫 화면
- ux-review-08 4.1(꺼진 노선도 + 이름 + 차량 그림 고르기 + 시승 운행 출발). 부모 안내 상자는 위 1.3으로 옮겼으므로 뺀다. 대신 맨 아래 한 줄(16px): `부모님과 같이 정한 대로 하루 2번 운행해요.`

## 2. 번호 없이 쓰던 기기 (지금 쓰고 있는 아이)

**원칙**: 아이 진행은 그대로 두고, 다음에 앱을 열 때 **부모에게 한 번 묻는다.** 막아 세우지 않는다(운행을 볼모로 잡으면 아이가 대충 번호를 정해 넘겨 버린다).

```
 앱을 연다 → 번호가 없다 → [부모님께 보여 주세요] 안내 화면
                                ├─ [부모님이 지금 정할게요] → 1.1 → 1.2 → 1.3 → 홈
                                └─ [나중에 할게요] → 홈 (그날 첫 운행이 끝난 뒤 일지 아래에 한 번 더)
```
안내 화면(어른용 모양):
```
  부모님께 보여 주세요
  이 앱에 부모님 번호가 아직 없어요. 번호를 정하면 부모 화면을 열고,
  운행 중에 "이번 운행 끝나면 쉬기"를 걸 수 있어요. 지금까지의 진행은 그대로예요.
  [ 부모님이 지금 정할게요 ]        [ 나중에 할게요 ]
```
- **"나중에"는 하루 한 번만** 다시 묻는다(앱을 열 때마다 묻지 않음 — 아이가 습관처럼 "나중에"를 누르게 됨). 다시 묻는 자리는 그날 첫 운행 일지 아래(아이 화면 흐름을 끊지 않음).
- 번호가 없는 동안:
  - 하루 운행 수는 기본값(2번).
  - 홈 [부모] 단추는 이 안내 화면을 연다(번호를 정하는 곳으로 바로 가지 않고, "부모님께 보여 주세요" 문구를 거친다).
  - 운행 띠의 쉬기 단추는 숨김(지금처럼).
- 이미 들어간 이름·차량 색·진행은 건드리지 않는다. 1.3 건네주기 화면은 "아이에게 돌려주세요"로 문구만 바꾼다.

## 3. 아이가 번호를 정해 버렸을 때 알아채고 되찾기
- 부모 화면 맨 위: `번호를 정한 때: 10월 4일 저녁 7:12` (부모가 정한 기억이 없으면 바로 알 수 있음).
- 번호 입력 화면 아래 작은 단추 `번호를 잊었어요` → 복구 번호 8자리를 넣으면 새 번호를 정한다. **진행·이름·기록은 그대로.**
- 복구 번호도 모를 때(아이가 처음 설정을 혼자 해서 부모가 본 적이 없음): `복구 번호도 몰라요` → 안내:
  - "진행은 지우지 않고 부모님 설정만 처음으로 돌릴 수 있어요. 아래 문장을 그대로 써 주세요: **부모 설정을 처음으로**" (글자 입력 칸, 시스템 키보드)
  - 문장을 맞게 쓰면 번호·복구 번호·하루 운행 수만 지우고 1.1부터 다시. 아이도 할 수 있는 방법이지만, 아이가 하면 "번호를 정한 때"가 다시 바뀌어 부모가 알 수 있다. 부드러운 문의 한계를 인정하고 **흔적을 남기는 쪽**을 택한다.
- 부모 화면의 "처음부터 다시 하기"(진행까지 지움)는 지금처럼 번호를 한 번 더 넣게 하고, 다른 단추와 떨어진 맨 아래에(07 A-10).

## 4. 화면에 쓰는 말 (정리)
| 자리 | 문구 |
|---|---|
| 부모님 단계 제목 | 부모님이 먼저 해 주세요 (1/2), (2/2) |
| 쉬운 번호 경고 | 아이가 맞히기 쉬운 번호예요. 다른 번호를 권해요. |
| 복구 번호 | 번호를 잊었을 때 쓰는 복구 번호예요. 적어 두거나 사진을 찍어 두세요. |
| 건네주기 | 아이에게 건네주세요 / (기존 기기) 아이에게 돌려주세요 |
| 기존 기기 안내 | 부모님께 보여 주세요 — 이 앱에 부모님 번호가 아직 없어요. … 지금까지의 진행은 그대로예요. |
| 부모 화면 | 번호를 정한 때: 10월 4일 저녁 7:12 |

## 5. 결정이 필요한 것
1. 복구 번호(8자리) 방식 채택 — 화면에 한 번 크게 보이므로, 아이가 옆에 있으면 볼 수 있다는 한계를 부모 안내에 적을지.
2. "부모 설정을 처음으로" 문장 입력 방식(복구 번호도 모를 때) — 채택하거나, 이 경우 기기 브라우저 데이터 지우기(진행도 지워짐) 안내만 둘지.
3. 기존 기기에서 "나중에"를 몇 번까지 허용할지(제안: 제한 없음, 하루 한 번만 다시 물음).
