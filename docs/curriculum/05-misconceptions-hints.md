# 1차 자문 ⑤ 3~4학년 수와 연산 오개념 → 오답 분류 → 힌트

> 커리큘럼 자문 · 2026-10-04
> 오답 분류 4가지(SPEC 3.5): **식**(식 세우기) / **계산**(계산 실수) / **읽기**(문제 잘못 읽기) / **개념**(개념 오해)
> 오답 숫자가 정해지는 오개념은 오답 분류 함수에서 **값으로 바로 잡을 수 있다**. "판별 오답" 칸이 그것이다.

## 1. 노선 전체에 걸친 오개념 (교통 앱 특유)

| 오개념 | 예 | 판별 오답 | 분류 |
|---|---|---|---|
| 역 수와 구간 수 혼동 | 서면→연산 4역째인데 4구간으로 셈 | 정답 ±1 | 개념 |
| 출발역 포함 여부 | "3번째 역"을 출발역부터 셈 | 정답 ±1 | 읽기 |
| 순환 노선 +1 실수 | 순환인데 일직선처럼 +1 | 정답 +1 | 개념 |
| 왕복에서 종점 두 번 세기 | 왕복 주기를 80구간으로 | 주기 +2 | 개념 |

## 3. 오답 분류 함수 작성 틀

```
classify(problem, answer, workSteps?):
  1. 빈칸·0·문제의 숫자를 그대로 → "대충 낸 답" (SPEC 3.7, 분류 대상 아님)
  2. 판별 오답 표에 있으면 → 그 분류 + 맞춤 피드백
  3. 식 입력이 있으면: 식이 틀림 → 식 / 식은 맞고 값이 틀림 → 계산
  4. 정답과 ±1 → (역·구간 문제면) 개념, 아니면 계산
  5. 문제 속 다른 수의 답(중간값, 다른 조건의 값) → 읽기 또는 식
  6. 그 밖 → 분류 보류("다시 보기"에서 아이에게 "어디서 막혔어?"를 묻기)
```
- 계산 실수와 개념 오해는 **같은 오답이 두 번 나오면** 개념으로 올린다(한 번은 실수일 수 있음).
- 부모 화면에는 분류 비율만, 아이 화면에는 "식 세우기에서 미끄러졌어요"처럼 짧게.

## 4. 힌트 4단계 작성 틀

| 단계 | 이름 | 하는 일 | 쓰는 규칙 |
|---|---|---|---|
| ① | 노선 확인 | **무엇을 묻는지, 어떤 조건이 있는지** 다시 짚는다. 숫자를 강조 표시 | 계산은 하지 않는다. 질문 형태로("몇 대가 **모두** 타야 하죠?") |
| ② | 경로 안내 | **어떤 연산·전략**을 쓸지 보여준다. 그림·표·선분도 비계는 여기서 처음. 문제를 풀기 위한 중간 질문("한 번 왕복하면 몇 구간?")도 여기서 | 식은 주지 않는다. 방향만. **전략을 하나로 고집하지 않는다**: 받아내림, 더해서 세기(237→240→300→400), 399+1처럼 여러 길을 고를 수 있게 (학생 4차) |
| ③ | 중간 정류장 | **첫 단계의 결과**를 주거나 식을 준다 | 마지막 계산과 판단은 남긴다 |
| ④ | 종착역 직전 | 빈칸 하나만 남긴 풀이 | 빈칸은 **핵심 판단**에 둔다(계산 끝자리가 아니라) |

### 예시: 3단계 "스카이캡슐 4인승, 27명 → 몇 대?"
- ① 노선 확인: "한 대에 몇 명이 타요? 모두 몇 명이 타야 해요? **모두**에 밑줄을 그어 볼까요?"
- ② 경로 안내: "4명씩 묶어 보세요. [사람 27명 그림, 묶기 도구]"
- ③ 중간 정류장: "27 ÷ 4 = 6 … 3. 6대가 꽉 차고 3명이 남아요."
- ④ 종착역 직전: "남은 3명도 타야 하니까, 캡슐은 6 + ☐ 대"

### 오답 분류와 힌트의 연결
| 분류 | 다음 힌트 시작 | 다음 문제 고르기 |
|---|---|---|
| 읽기 | ① (조건 강조) | 같은 단계, 문장 구조가 다른 문제 |
| 식 | ② (전략 그림) | 같은 단계, 그림이 있는 문제 |
| 계산 | ③ (중간값 확인) | "정비창 점검" 맨 계산 2~3개 |
| 개념 | ② + "왜 그런지" 해설 | 한 단계 낮은 문제 → 다시 원래 단계 |
