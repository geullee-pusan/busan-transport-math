## 2. 영재원 선발 방식 요약

### 2.1 큰 틀
- 영재교육원·영재학급은 **교사관찰추천제**로 뽑는다. 목적은 사교육·선행학습 효과를 줄이고 잠재력 있는 아이를 찾는 것이다[10]. 2022년 기준 전국 기관의 77.4%가 교사관찰추천 요소를 반영했다[10]. 2010년 시범, 서울은 2012학년도부터 지필고사 없이 관찰추천으로만 뽑았다[44].
- 모든 지원·추천·결과 처리는 **GED(영재교육종합데이터베이스, 한국교육개발원 운영)** 에서 한다. 흐름: 학생·학부모 온라인 지원 → 담임 등 추천 교사의 관찰·추천서 → 학교추천위원회 → 영재교육기관 선정심사[10][11].
- 선발 원칙은 "현재 성취보다 미래 가능성"이다. KEDI 영재성 검사도 **선행지식이 아니라 잠재력 중심, 실생활 문제**로 만든다고 밝힌다[15][17].

채점 관점(공개 연구 기준. KEDI 수학 채점표는 비공개 — 확인 필요):
- **유창성** = 맞는 답·풀이의 개수, **융통성** = 서로 다른 갈래(전략·범주)의 개수, **독창성** = 집단 안에서 드문 정도[21][27]. 유창성·융통성이 커지면 독창성은 오히려 낮아질 수 있어서 따로 본다[21].
- **정교성** = 아이디어를 구체적으로 다듬음, **민감성** = 문제·빠진 것을 알아챔[16].
- 서술형 경시(KMC)는 계산·이해·적용·문제해결 네 영역으로 본다[38].
- 개방형 문제를 평가 과제로 쓰면 유창성·융통성이 자란다는 결과가 있다[22]. 문제 만들기는 확산적 사고를 끌어낸다[23][28].

### 2.5 우리 앱에 주는 뜻
1. **잠재력·과정을 본다** → 앱도 "선행 진도"가 아니라 **같은 도구를 새 상황에 쓰기**(비정형성 축)를 올린다. 동해선 X 노드가 맞는 자리다. 학년 밖 공식을 미리 가르치지 않는다(04 7단계 검수 규칙과 같음).
2. **거꾸로·규칙 추론·대칭**이 수학 영재성 검사의 명시된 관점이다[17] → X02, X04, X07을 우선한다.
3. **여러 답·여러 풀이**가 창의성 채점의 중심이다[12][16][21] → 모든 X 노드 마무리에 "더 있나요?"(유창성), "다른 풀이 고르기"(융통성), "빠진 조건 고르기"(민감성·정교성)를 붙인다(4절). `knowledge.md` G5 결정과 같다.
4. **면접·서술 대비는 입력 형식으로 바꾼다**: "왜 그런지 설명" → **이유 고르기**(choice), "다른 방법" → **다른 풀이 고르기**(multi), "조건을 바꾸면" → **바뀐 답 고르기 + 무엇이 바뀌었나**. 소리 내어 설명하는 연습은 연습장(채점 안 함)과 부모 안내문에 맡긴다.
5. **시험처럼 보이지 않게**: 제한 시간, 점수, 합격선, "기출", "영재원", 학년 표시를 아이 화면에 두지 않는다. 동해선은 "어려운 길을 골라 가는 기차"로만 보인다(6절).

## 4. 채점이 어려운 유형 바꾸기

서술형 자동 채점이 없으므로, 영재 검사의 "설명하기·여러 답·만들기"를 **고르기·놓기·칸 채우기**로 바꾼다. 원칙은 "생각은 그대로, 쓰는 일만 줄인다"이다.

### 4.1 바꾸기 규칙
| # | 원래 발문 | 우리 형식 | 규칙 |
|---|---|---|---|
| R1 | 답을 모두 쓰시오 | **multi** + "더 있나요?" 버튼 | 정답 전부를 고르면 ✓. 일부만 고르면 ⏸ + "몇 개 더 있어요"(개수만 알려 줌). 틀린 것을 고르면 그것만 되돌림. 보기에 판별 오답(조건 하나만 만족)을 섞는다 |
| R2 | 여러 답을 쓰시오(답이 너무 많음) | **number(개수)** + 그중 2~3개 **compound** | 개수와 예시를 따로 채점. 예시는 채점 함수가 조건을 검사(정답 목록 대조가 아님) |
| R3 | 왜 그런지 설명하시오 | **이유 고르기 choice**(보기 3~4개: 맞는 이유, 결과만 다시 말함, 그럴듯한 틀린 이유, 관계없는 사실) | 04 2절 11단계 (가)의 형식. 보기는 아이 말투로 |
| R4 | 다른 방법으로 풀어 보시오 | **다른 풀이 고르기 multi**: 풀이 그림·식 3~4개 중 맞는 것 모두 → 이어서 "처음 고른 것과 생각이 다른 것" choice | 융통성 = 갈래가 다른 풀이를 알아봄 |
| R5 | 조건을 바꾸어 문제를 만드시오 | **조건 바꾸기**: 바꿀 조건을 앱이 제시(또는 둘 중 아이가 고름) → 새 답 number + "무엇이 바뀌었나" choice | What-If-Not[28]. 아이가 바꿀 조건을 **고르는** 단계까지만 열어 둔다 |
| R6 | 문제를 만드시오 | (가) **질문 고르기 multi**: 장면 정보로 답할 수 있는 질문 모두 (나) **수 채우기 cards**: 빈칸에 수를 넣어 답이 주어진 값이 되게 (채점 함수가 생성한 문제를 풀어 확인) | 자유 작문은 **연습장**(채점 안 함) |
| R7 | 그림을 그려 설명 | **paint / place / 경로 그리기 / 원 위 점** | 그림 자체를 채점(칸 집합, 경로 순서) |
| R8 | 빠진 것을 찾으시오 | **빠진 조건 고르기 choice / multi** | 민감성·정교성 |
| R9 | 과정을 쓰시오 | **중간값 compound**(예: 거꾸로 풀기에서 역마다 수) | 과정의 핵심 칸만. 칸 수는 3개 이하 |

### 4.4 바꿀 때 잃는 것 (정직하게)
- **말로 설명하는 힘**: 이유 고르기는 "알아보기"이고 "만들어 말하기"가 아니다. 보기가 힌트가 된다. → 연습장과 부모 안내문("아이에게 왜 그런지 말해 보게 해 주세요")으로 보완. 면접 대비를 앱이 다 맡지 않는다고 부모에게 밝힌다.
- **독창성**: 비교 없이 잴 수 없어서 버린다. 앱 원칙(순위·비교 없음)이 우선이다.
- **스스로 질문 만들기**: 질문 고르기는 보기 안에서만 논다. 자유 문제 만들기는 연습장에만 둔다.
- **부분 점수**: 서술 채점의 "과정 점수"가 없다. 중간값 칸(R9)이 일부를 대신하지만, 앱은 점수 대신 ✓/⏸와 힌트 단계로 처리한다.
- **찍기 위험**: multi와 choice는 찍을 수 있다. 꼼수 원칙대로 **찍어 맞힌 길은 보상이 작게**(예: 같은 구조 다른 수로 한 번 더 맞혀야 깊이 도장, 보기 순서는 씨앗값으로 섞기).

## 6. 주의 (표현과 압박)

- **아이 화면에 쓰지 않는 말**: "영재원", "영재", "기출", "선행", "경시", "시험", "합격", 학년(초4 과정 등), 점수, 등급. 동해선은 "생각이 많이 필요한 길"로만 소개한다.
- **순위·비교 없음**: "다른 친구보다 많이 찾았어요", "상위 몇 %" 같은 말 금지. 유창성 보상은 **자기 기록**(이 문제에서 찾은 답 수)만, 그리고 놓쳐도 잃는 것이 없게.
- **시간 없음**: 실제 검사는 60~90분 제한이지만[15], 앱에는 타이머·카운트다운·"빨리 풀기"를 두지 않는다. GF-41(일 순서)·GF-42(배차)처럼 문제 속 시간은 괜찮지만, 아이의 풀이 시간을 재거나 보상에 쓰지 않는다.
- **어려움의 신호를 부드럽게**: 9~11단계는 "이번엔 끝까지 못 가도 괜찮아요. 다음에 이어서 해요"(⏸). 큰 실패 연출 없음. 정답·오답에 색 쓰지 않음.
- **부모 안내문**(아이 화면 밖)에만: "영재교육원 선발은 교사 관찰·추천과 잠재력 중심이며 선행학습을 요구하지 않는다고 공식 안내되어 있습니다[10][15][17]. 이 앱의 동해선은 그 방향(규칙 찾기, 거꾸로 생각하기, 여러 답 찾기, 이유 말하기)을 연습하는 곳이지 시험 대비 문제집이 아닙니다. 말로 설명하기는 아이와 대화로 연습해 주세요."
- **사실 쓰기**: 교통 장면 숫자는 FACTS ✅ 값(1호선 8량·40역, 2호선 43역·6량, 환승역 11곳, 해변열차 7곳, 스카이캡슐 4인승, KTX-이음 2021·KTX-청룡 2024 첫 운행)만 단정한다. 그 밖은 "어느 날"(그날 상황) 또는 "~라고 해 봐요"(가정). 바둑판 도로는 FACTS ❌라서 **가상 신도시**로만 쓴다. 노선 색은 FACTS 🟡이므로 퍼즐 장식으로만 쓰고 사실처럼 말하지 않는다.
- **저작권**: 이 문서의 예시는 모두 새로 지었다. 템플릿을 만들 때도 문제집·기출의 수와 장면을 쓰지 않는다. 공개 목차는 "어떤 유형이 흔한가"의 근거로만 쓴다.
