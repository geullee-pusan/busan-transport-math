## 1. UX 6차 결론에 대한 시각 쪽 의견
| UX 6차 | 의견 |
|---|---|
| 개통 = 흰 원 + 굵은 진한 테, 확정 = 진한 꽉 찬 원 + 노선 색 점 | 확정(01안 그대로) |
| **노선 색 꼬리**(반지름 + 6px, 구간 절반 이하) | **동의.** 견본에서 혼자 켜진 역이 흰 선로 위에서도 "색 위의 흰 점"으로 읽힌다. 흑백에서는 회색 꼬리로 남아 ② 갈 수 있음과 구분된다. 구현은 `stationTail()` |
| 개통 예정 `#5E6B76` 3px 점선 | 확정 |
| 크기를 화면 위 역 간격 g로, 지름 ≤ 0.8g | **동의, 한 곳 보완**: g < 20의 개통 점 r5 + 테 2.5는 지름 12.5px라 g = 15에서 0.8g(12)를 넘어 이웃 점과 거의 붙는다(견본 확인). **r4.5 + 테 2.2(지름 11.2), 확정 r5(지름 11.5)** 로 줄였다 |
| "지금 역" 고리 삭제, 차량 표지를 선로 바깥 18px + 지시선 | **동의.** 보완: g < 20에서는 지시선 끝의 진행 점(r3.5)이 목적지 이중 고리와 겹친다 → 촘촘할 때는 진행 점을 그리지 않고(`dot: false`) 지시선만, **목적지는 차량 표지보다 나중에(맨 위)** 그린다 |
| 홈 첫 화면 = 확대 보기 + [1호선 전체 ⤢] + 미니맵 | 동의. 미니맵 모양은 3절 |

## 2. 크기 표 (화면 px, `TIERS` · `sizeTier(g)`)
| 상태 | g ≥ 32 `zoom` | 20 ≤ g < 32 `mid` | g < 20 `dense` |
|---|---|---|---|
| ① 아직 못 감 | r5.5, 테 2 `#7A8691` | r4, 테 1.5 | 그리지 않음 |
| ② 갈 수 있음 | r6.5, 테 2.5 | r5, 테 2 | 그리지 않음 |
| ③ 목적지 | r11 / 안 r5, 테 2.5 | r9 / 4 | r8 / 3.5 — 맨 위에 |
| ④ 개통 | r8, 테 3.5 + 꼬리 | r6, 테 3 + 꼬리 | r4.5, 테 2.2 + 꼬리 |
| ⑤ 통과 | ④ + ≫ 10px | ④ + ≫ 8px | ④ + 이름 옆 ≫(이름을 쓸 때만) |
| ⑥ 확정 | r8.5 + 노선 색 점 r3.5 + 꼬리 | r6.5 + 점 r2.5 | r5 진한 채움 |
| 환승 캡슐 | 26×16 | 20×13 | 16×11(늘 그림) |
| 이름 | 모두 | 켜진 역·목적지·환승·종점 | 목적지, 켜진 역 양 끝, 환승, 종점 |
| 선로 | 테두리 10 + 속 7 | 같음 | 같음 |
| 배지 | 32 | 32 | 24 |

- **표지는 화면 크기를 지킨다.** `map.js`는 지도 축척 `scale`(사용자 단위 1 = 화면 scale px)로 `u = 1/scale`을 구해 모든 함수에 `{ u }`로 넘긴다. 지도를 확대해도 점·선·차량이 같이 커지지 않는다.
- g는 화면에 보이는 구간들의 이웃 역 간격 중 **가장 작은 값**(또는 하위 10% 값)으로 한 번 정하고, 한 화면 안에서는 한 단계만 쓴다(구간마다 크기가 다르면 상태가 크기로 오해됨).
- 그리는 순서: 선로 바깥 테두리 → 흰 속선 → 켜진 구간 속선 → 진행 속선 → 꼬리 → 역 점(목적지 빼고) → 이름 → 차량 표지 → **목적지**.
- 차량 표지 `normal`은 이름이 놓인 쪽의 반대쪽. 1호선은 이름을 왼쪽에 몰아 두므로(지금 `map.js`) 오른쪽 위 방향 수직 벡터를 쓴다.

## 3. 미니맵 (`miniMap(points, lit, here, color)`)
- 140×140 판(흰 바탕, 진한 테 1.5, 둥글기 10), 1호선 전체 선 하나: 테두리 6 + 흰 속 3.5, 채운 길이만 노선 색. 지금 위치는 진한 ▲(흰 테). 역 점·이름·숫자 없음.
- `lit`은 "켜진 구간 끝까지의 노선 길이 비율", `here`는 차량 위치 비율. 떨어져 켜진 섬은 미니맵에 그리지 않는다(채운 길이는 연속 구간만 — 운행 띠의 "40역 중 N역 켜짐"이 수를 맡는다).
- 누르면 [1호선 전체 ⤢]와 같은 동작. 누르는 영역은 판 전체(48px 이상).
- 놓는 곳: 확대 보기의 오른쪽 아래 구석, 지도 판 안쪽 12px. 차량 표지·목적지와 겹치면 왼쪽 아래로.

## 4. 남는 확인
- 확대 보기에서 g ≈ 37은 1호선 앞쪽(촘촘한 구간) 기준이다. 뒤쪽(지도 단위 18~22)에서는 g가 54~66까지 커지므로 같은 `zoom` 단계를 쓰되 확대 배율을 목적지 주변 간격에 맞춰 조금 줄여도 된다(UX 결정 범위).
