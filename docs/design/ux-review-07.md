# UX 자문 7차 — 새 판(26117e4) 검토, 기준 기기 1480×924 / 924×1480

> 작성: UX 자문, 2026-10-04
> 본 것: 배포판(가로 1480×924, 세로 924×1480) — 처음 화면 → 시승 운행 8문제 → 일지 → 홈 → 보통 운행(오답, 힌트 ①~④, 넘기기, 쉬어 갈까 제안) → 일지 → 차고. 부모 화면은 같은 판을 로컬 미리보기(localhost:4174)에서 시험용 번호로 열었다(검토 뒤 그 저장소는 비움).
> 못 본 것: 2호선 시범 구간(홈에서 들어가는 입구를 못 찾음), "이번 운행 끝나면 쉬기"의 실제 흐름, 여럿 고르기·순서·색칠·식 입력(이번 판 문제 순서에서 나오지 않음). 화면 캡처가 중간부터 안 돼서 뒤쪽은 DOM 측정으로 봤다.
> 배포판 저장소의 기존 진행("이로")은 백업했다가 그대로 되돌렸다.
> 시승 운행이 사이 역을 켜지 않는 결함은 다음 판에서 바뀐다고 해서 그 흐름 자체는 문제로 세지 않았다. 단, 화면 문구 문제(아래 A-3)는 남긴다.

## 확인된 개선 (5차 지적 반영)
- 부모 화면 열림, 번호 두 번 확인 ✓
- 열차 그림 칠한 칸 숫자 처리 ✓(시승 "3량 색칠" 그림에 3칸)
- 맨 계산 수 표시 없음 ✓, 이번 운행의 이야기 문제는 지어낸 숫자 표시가 고르게 붙음 ✓
- 가로 홈 2단(지도 875×791, 오른쪽 칸), 스크롤 없음 ✓ / 세로 홈·운행 화면도 한 화면 ✓
- 힌트 ④를 열면 서랍이 닫히고 답 칸이 빈칸 틀로 ✓, 빈칸을 맞히면 전체 답(385) 채움 ✓
- "3칸 반" ✓, "오늘 100 m 달렸어요"(정수 + m) ✓, 취소선 `#5E6B76` ✓
- 선 문법: 빈 답 내기 = 점선 + "답을 먼저 써요" ✓, 못 얻은 카드 = 점선 + 조건 ✓, 고른 선택지 = 흰 바탕 + 4px 테 ✓
- 문제 글자 26px(가로), 키 72px ✓, 일지 끝 단추 72px 같은 크기 ✓

## A. 이번 판의 새 문제 (우선순위 순)

| # | 등급 | 문제 | 본 곳 | 고칠 방법 |
|---|---|---|---|---|
| **A-1** | **P0** | **거의 다 틀린 운행에서 면허가 올랐다.** 보통 운행에서 8문제쯤을 두 번 틀리고 넘겼는데(맞힌 것은 ④ 빈칸으로 푼 1개), 일지의 큰 소식이 **"급행버스 운행 허가"** 였다. 근거 문구는 "장림 · 하단 · 당리역에서 이 단계 문제를 풀어서 올랐어요"(시승에서 맞힌 역)다. 게다가 **홈과 차고의 면허는 "도시고속버스"(3단계)** 이고 카드도 1·2·3이 들어와 있다. 일지는 2단계를 말했는데 저장된 것은 3단계라, **한 단계는 알림 없이** 올랐다. | 보통 운행 일지 → 홈 → 차고 | ① 면허 오름 판정은 **운행이 끝난 시점의 그 운행 기록**과 함께 보고, 넘긴 문제가 많은 운행(예: 넘김 2개 이상)에서는 면허 연출을 다음 운행으로 미룬다. 실패한 날 축하를 받으면 아이는 축하를 믿지 않게 된다. ② 한 번에 두 단계 이상 오르면 일지에 **도착한 단계 하나**로 알리고, 받은 카드는 모두 적는다. ③ 시승 운행 결과는 시승 일지에서 정하고, 그다음 첫 보통 운행에서 다시 오르지 않게. |

| **A-3** | P1 | **시승 일지 제목과 다음 출발역이 서로 다르다.** 제목 "1호선 당리역 도착" + 큰 소식 "장림 · 하단 · 당리역 통과!" 아래에 "다음 운행은 **다대포해수욕장역** 앞에서 출발해요." 아이는 "당리까지 왔는데 왜 처음으로 돌아가?"가 된다. | 시승 일지 | 시승 일지 제목은 `시승 운행 결과`. 큰 소식은 `아는 역 3곳에 불을 켰어요`. 다음 줄은 `운행은 아직 안 켠 첫 역, 다대포해수욕장부터 시작해요`처럼 **왜 거기서 시작하는지**를 쓴다. 시승 수정판에서도 같은 원칙(도착 ≠ 출발이면 이유를 한 줄로). |
