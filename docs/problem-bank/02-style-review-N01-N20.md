- **좋은 점**: "~해요"체가 고르다. 숫자 뒤 자동 조사(2/7를, 5/8예요, 1032예요, 39.9를)는 N01~N10에서 틀린 곳이 없다. 번역투·어른 한자어("해당", "총", "구하시오")는 거의 없다. "어느 날"·"~라고 해 봐요" 규칙을 잘 지킨다. 피드백은 거의 모두 길이 기준 안이다. 교통 사실 오류는 찾지 못했다.

#### A3-4. 문체 밖이지만 눈에 띈 것

- **사실(FACTS).** "1호선 39.9km·8량·역 순서"는 FACTS와 맞음. 사하–괴정, 사하–당리 거리와 사하역 출구–정류장·공원 거리는 FACTS에 없음(위 상·중 항목).
- **표본 출력의 `D(undefined, …)`.** equation·multi 입력의 `match` 함수형 판별 오답은 값이 없어 이렇게 찍힘. 문구 자체는 위에서 검토함. T2-1 L3에서는 같은 문구 "빌려 준 자리는…"이 두 번 나옴.
- **N10 T10-3 L3 D(11) 중복.** 같은 값 11에 피드백이 둘("0.1이 10개면 1이에요. 11개면요?" / "1을 빼고 나면 0.1이 몇 개 남아요?"). 뒤의 것은 나올 일이 없음.
- **N06 T6-1 L5 D.** 판별 오답 값에 보기에 없는 "2칸 18명"이 들어 있어 실제로는 걸리지 않음.
- **띄어쓰기 확인 결과.** "찾아봐요"(찾아보다는 한 낱말), "그다음", "늘어놓아요", "몇백", "빌려 와요"는 맞음. 틀린 것은 "빌려 준/빌려 주고/빌려 줘서/빌려 줬어요"(→ 붙여 씀)뿐임.
- **단위 표기.** 1000·1270처럼 네 자리 수에 쉼표를 붙이지 않은 것은 2~3학년 교과서 표기와 같음. "0.7km"처럼 붙여 쓴 것도 "3명"과 일관됨. 교과서 인쇄본은 "0.7 km"처럼 반 칸을 띄우기도 하지만, 화면에서는 지금처럼 두는 쪽을 권함.
