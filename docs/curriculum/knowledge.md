## 1. 2022 개정 수학과 교육과정 (설계에 직접 쓰이는 것)

### 1.1 구조
- 영역은 수와 연산 / 변화와 관계 / 도형과 측정 / 자료와 가능성 4개(L47). 2015 초등은 5개였다(2차: [교육신문 임해미 칼럼](http://kuen.korea.ac.kr/news/articleView.html?idxno=1126)).
- 내용 체계 = 핵심 아이디어 + **지식·이해 / 과정·기능 / 가치·태도** 3범주(L46, L49). 과정·기능은 5개 교과 역량(문제해결, 추론, 의사소통, 연결, 정보처리)이 드러나는 사고 과정이다.
- 평가는 세 범주를 학습 결과와 학습 과정에서 고르게 본다(L978). 역량별 평가 관점(L990–994): 문제해결 = 조건 분석·전략 탐색·과정 반성·끈기, 추론 = 근거 제시·정당화, 의사소통 = 표현 바꾸기, 연결 = 실생활 적용, 정보처리 = 자료 정리·도구 활용.
- 지필평가는 선택형·단답형·서·논술형(L996). 온라인 플랫폼으로 수행 과정을 관찰하고 개별 환류할 수 있다(L1007) → 앱의 풀이 기록과 맞는다.

## 4. 수학교육 연구

### 4.1 오개념은 체계적인 "버그"다
- 받아올림·받아내림 오류는 무작위가 아니라 절차를 조금 바꾼 규칙에서 나온다. 막힌 곳을 국소적으로 "수리"하다 버그가 생기고, 같은 학생의 버그가 며칠 사이 다른 버그로 옮겨 가기도 한다(bug migration) → **한 번의 오답으로 개념 오류를 확정하지 않는다.** [Brown & Burton 1978](https://onlinelibrary.wiley.com/doi/10.1207/s15516709cog0202_4), [Brown & VanLehn 1980 Repair Theory](https://www.lri.fr/~mbl/Stanford/CS477/papers/RepairTheory-SeelyBrown.pdf)
- 대표 버그: 큰 수에서 작은 수 빼기, 받아내림 안 함, 0에서 받아내림(0을 9로 바꾸고 윗자리를 안 줄임), 0에서 멈춤, **위 숫자 0인 자리에서 아래 숫자를 그대로 씀(0 − N = N)**. 진단 문항은 버그마다 다른 오답이 나오게 고른다: 받아내림 없음 / 한 번 / 중간 0을 건너는 받아내림(403 − 158) / **위 숫자가 0인 자리(340 − 126)** / 연속 받아내림.
- 국내 초3: 덧셈은 받아올림·자릿값, 뺄셈은 받아내림·0 처리 오류가 주로 나오고 대부분 일관적이었다. 수 모형으로 자릿값을 다시 연결하자 고쳐졌다(검색 요약) [교과교육학연구 10(2) 2006](https://scholar.kyobobook.co.kr/article/detail/4050025578471).

### 4.2 분수
- 자연수 편향: 분자·분모를 따로 보는 경향 [Ni & Zhou 2005](https://www.semanticscholar.org/paper/Teaching-and-Learning-Fraction-and-Rational-The-and-Ni-Zhou/c275d8d7b0b7a728555e9d0c3a628f82d6420d7f), [Siegler 외 2011](https://www.semanticscholar.org/paper/An-integrated-theory-of-whole-number-and-fractions-Siegler-Thompson/1b2dd46ca0b6e540ddf95433baf8bdafe24e2605).
- IES 분수 지침([Siegler 외 2010](https://ies.ed.gov/ncee/wwc/docs/practiceguide/fractions_pg_093010.pdf)): ① 공평하게 나누기에서 시작(최소) — 여러 물건 → 한 물건(단위분수) → 비단위분수, ② **분수도 수, 수직선을 중심 표상으로**(중간), ③ 계산 절차의 이유·어림·오개념 직접 다루기(중간). 부분-전체만 가르치면 가분수를 "수가 아니다"라고 여긴다.
- 4학년 무작위 실험에서 분수 이해 향상을 매개한 것은 부분-전체가 아니라 **측정(수직선) 해석**이었다 [Fuchs 외 2013](https://eric.ed.gov/?id=EJ1054396).
- 공평하게 나누기의 세 기준: 정해진 수만큼 / 크기를 같게 / **남김없이** [Confrey 외 2015](https://link.springer.com/article/10.1007/s11858-015-0699-y). 어린 학생은 "조각 수가 같음"과 "양이 같음"을 혼동한다(IES).
- 국내 초3: 부분에서 전체를 찾는 과제에서 단위와 전체 구분 경험이 부족했다 [임미인 2020](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART002611768).

### 4.3 소수
- 오류 원천: 자연수 규칙 적용, 분수 해석 잘못 [Resnick 외 1989](https://colab.ws/articles/10.5951/jresematheduc.20.1.0008).
- [Steinle & Stacey 1998](https://www2.merga.net.au/documents/RP_Steinle_Stacey_1998.pdf): 5~10학년 2,517명, **긴 쪽이 크다 13.1% / 짧은 쪽이 크다 13.1%**. 짧은 쪽이 크다(역수형: 0.3 > 0.4를 1/3 > 1/4처럼 봄 등)는 수업 중에 잘 드러나지 않는다. 판별 묶음: 4.8 / 4.63, 5.736 / 5.62, 4.7 / 4.08, 4.4502 / 4.45, **0.4 / 0.3**, 0.42 / 0.35. 묶음당 4~5문항으로 일관성을 본다. 돈 맥락만 쓰면 둘째 자리 뒤를 버리는 사고가 굳을 수 있어 **km처럼 셋째 자리까지 쓰는 맥락**을 섞는다.
- 맞는 예와 틀린 예를 비교하게 하면 소수 오개념이 줄었다 [Durkin & Rittle-Johnson 2012](https://www.researchgate.net/publication/257408490_The_effectiveness_of_using_incorrect_examples_to_support_learning_about_decimal_magnitude).

### 4.4 나눗셈
- 나머지 해석: "버스 몇 대?" 문제 정답률 약 24%, 원인은 계산이 아니라 **결과를 상황에 맞게 해석하는 데 실패** [Silver, Shapiro & Deutsch 1993](https://files.eric.ed.gov/fulltext/ED342645.pdf). 국내 6학년 177명: 하위권은 식 오류, **상위권은 해석 오류** [하미현·장혜원 2016](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART002166416).
- 해석의 네 갈래: 올림 / 버림 / **나머지가 답** / 소수·분수 답.
- 등분제가 직관적 원형이고 포함제는 수업으로 나중에 익힌다 [Fischbein 외 1985](https://files.eric.ed.gov/fulltext/ED676436.pdf). 한국은 3학년에 두 의미를 함께 도입.
- 몫 가운데 0 빠뜨림(812 ÷ 4 → 23)은 과잉 일반화된 규칙으로 설명된다(검색 요약) [Springer](https://link.springer.com/content/pdf/10.1007/978-3-642-84256-6_13).

### 4.5 큰 수·자릿값
- 한국어는 네 자리(만·억·조), 쉼표는 세 자리로 묶는다(사실). 이 불일치가 초등생 오류에 주는 영향의 **한국 실증 연구는 확인 못 함** → 앱 기록으로 검증한다.
- 초3 학습부진아는 앞 학년에서 배웠어도 자릿값 개념을 매우 어려워했다 [장혜원 외 2015](https://www.kci.go.kr/kciportal/ci/sereArticleSearch/ciSereArtiView.kci?sereArticleSearchBean.artiId=ART002025254). 자리 지킴이 0을 "아무것도 없음"으로 보는 오류(206 → 26) [USU](https://digitalcommons.usu.edu/cgi/viewcontent.cgi?article=3401&context=teal_facpub).

### 4.6 학습 궤적
- 학습 궤적 = 목표 + 사고 수준의 발달 단계 + 단계별 과제, 셋은 떼어 놓을 수 없다 [Clements & Sarama](https://www.learningtrajectories.org/), [2004](https://www.researchgate.net/publication/233300911_Learning_Trajectories_in_Mathematics_Education). 궤적은 **가설**이라 자료로 고쳐 간다.
- 인지 기반 평가: 학생의 수준을 판별하고 그 수준에 맞춰 지도 [Battista](https://www.heinemann.com/products/e04345.aspx).
- 분수 궤적(IES): 나누기 직관 → 단위분수 → 비단위분수 → 수직선 → 동치·비교 → 계산 → 비례.

### 4.7 CPA와 구체성 점감
- 구체 → 그림 → 기호로 단계적으로 옮겨 가는 방식(구체성 점감)이 구체만·추상만보다 낫다 [Fyfe 외 2014](https://link.springer.com/article/10.1007/s10648-014-9249-3). 막대 모델은 기호 대수 이전에 문장제를 표상하게 한다 [Ng & Lee 2009](https://eric.ed.gov/?id=EJ838947).
- IES 문제해결 지침: **시각적 표상 사용 지도(강)**, **풀이 점검·성찰(강)**, 여러 전략 노출(중간), 수학 언어 표현(중간) [Woodward 외 2012](https://ies.ed.gov/ncee/wwc/PracticeGuide/16). 표상은 계산 구조와 맞아야 하고, 어떤 표상은 오개념을 강화한다(IES 분수).

### 4.8 문제해결 전략·풀이 예제
- Pólya 4단계: 이해 → 계획 → 실행 → 되돌아보기 [How to Solve It](https://en.wikipedia.org/wiki/How_to_Solve_It).
- 스키마 지도: 문장제 유형(변화 / 합병·전체 / 비교 / 같은 묶음)을 알아보고 유형별 도식에 수를 놓는다 [Powell 2011 리뷰](https://pmc.ncbi.nlm.nih.gov/articles/PMC3105905/). 메타분석 g = 1.57(전이 1.09)이지만 연구자 제작 검사가 많아 부풀려졌을 수 있다 [Peltier & Vannest 2017](https://eric.ed.gov/?id=EJ1153429). 전이 특징(형식 변화, **필요 없는 정보**, 낯선 어휘, 추가 질문, **표 속 정보**, **미지수 위치 변화**)을 명시적으로 가르친다 [Fuchs 외 2004](https://www.researchgate.net/publication/250184938_Expanding_Schema-Based_Transfer_Instruction_to_Help_Third_Graders_Solve_Real-Life_Mathematical_Problems).
- 풀이 예제 효과 평균 g = 0.48(주로 중등) [Barbieri 외 2023](https://link.springer.com/article/10.1007/s10648-023-09745-1). 단계를 하나씩 비워 가는 점감 예제가 효과적 [Renkl & Atkinson 2003](https://link.springer.com/article/10.1023/B:TRUC.0000021815.74806.f6). 초보자에게 좋은 안내가 숙련자에게는 방해(**전문성 역전**) [Kalyuga 외 2003](https://mrbartonmaths.com/resourcesnew/8.%20Research/Explicit%20Instruction/The%20Expertise%20Reversal%20Effect.pdf). 틀린 예는 맞는 예와 **나란히 대조**할 때 쓴다(Booth 외 2013, Durkin & Rittle-Johnson 2012).

### 6.4 그대로 두어도 되는 것 (근거와 맞음)
- 숙달: 칸 방식(혼자 정답 4칸, 마지막 칸 3단계 힌트 없이, 표현 2가지, 최근 5문제 중 3개 정답) + 다른 날 확정 → "3연속이면 대체로 충분"과 지연 확인 권고에 맞는다.
- 복습 1·3·7·14일 + 같은 템플릿 다른 씨앗으로 **다시 풀기** + 같은 유형 최대 2연속(교차) → 간격·인출·교차 근거와 맞는다.
- 힌트 ① → ④ 순서, 첫 오답 check → 두 번째 nudge(검증 → 정교화), ④ 뒤 쌍둥이 문제(ASSISTments의 마지막 힌트 문항 제외 방식) → 맞는다.
- 사실형 피드백("서면역 개통!"), 사람을 향한 칭찬 없음 → Hattie & Timperley·Kluger & DeNisi와 맞는다.
- 1호선 순서와 교과서 단원 흐름 → 맞는다(2절).
