## 1. 노선 색 대비와 사용 규칙

### 1.1 대비 표 (WCAG 2.x 상대 휘도로 계산)

글자색 후보: 흰색 `#FFFFFF`, 검정 `#000000`, 앱 글자색 `#1F3342`(형제 앱과 같음).
바탕 후보: 육지 `#EDF1EC`, 바다 `#B9D4E6`.

| 노선 | 색 | 흰 글자 | 검은 글자 | 글자색 `#1F3342` | 육지 위 (선·점) | 바다 위 (선·점) |
|---|---|---|---|---|---|---|
| 1호선 | `#F7941D` | 2.28 ✗ | 9.21 ✓ | **5.72 ✓** | 2.00 ✗ | 1.48 ✗ |
| 2호선 | `#AFD46B` | 1.69 ✗ | 12.45 ✓ | **7.73 ✓** | 1.48 ✗ | 1.09 ✗ |
| 3호선 | `#D69B3D` | 2.44 ✗ | 8.62 ✓ | **5.35 ✓** | 2.14 ✗ | 1.58 ✗ |
| 4호선 | `#6E8CC0` | 3.40 △ | 6.18 ✓ | 3.83 △ | 2.98 ✗(아슬) | 2.21 ✗ |
| 부산김해경전철 | `#895FA7` | **4.93 ✓** | 4.26 △ | 2.64 ✗ | 4.32 ✓ | 3.20 ✓ |
| 동해선 | `#0065B3` | **5.98 ✓** | 3.51 △ | 2.18 ✗ | 5.24 ✓ | 3.88 ✓ |

기준: 보통 글자 4.5 이상 ✓ / 굵은 큰 글자(약 19px 굵게 이상)만 3.0 이상이면 △ / 선·점 같은 그래픽은 3.0 이상 ✓.
참고: 글자색 `#1F3342` / 육지 = 11.42, / 흰색 = 13.04.

읽는 법
- **노선 색 위의 글자**: 1·2·3호선은 진한 글자색(`#1F3342`), 경전철·동해선은 흰 글자. **4호선은 어느 쪽도 보통 글자 기준에 못 미친다** → 4호선 배지 숫자는 굵게 20px 이상으로만 쓰고(큰 글자 기준 통과), 작은 글자는 4호선 색 위에 쓰지 않는다. 검정(`#000000`)은 6.18로 통과하지만 앱 전체 글자색과 달라 보이므로 배지 숫자에만 예외로 쓰는 것도 방법이다(선택).
- **노선 색 선을 육지·바다에 그대로 그리면 1~4호선 모두 3:1 미만**이다. 특히 2호선 연두는 바다 위에서 1.09로 사실상 안 보인다(광안리 쪽 해안 구간 등, 실제 선형은 확인 필요). → 1.3절의 **테두리 규칙**이 필수다.

### 1.2 노선 번호 배지
```
 ┌──┐
 │ 1│   지름 32px(홈·띠), 24px(카드·일지 안), 원형
 └──┘   바탕 = 노선 색, 글자 = 1.1절 규칙, 테두리 1.5px #1F3342
```
| 노선 | 배지 글자 | 배지 표기 |
|---|---|---|
| 1·2·3호선 | `#1F3342` 굵게 | 1 / 2 / 3 |
| 4호선 | `#1F3342` 굵게, 20px 이상 | 4 |
| 부산김해경전철 | 흰색 굵게 | 경 (확인 필요: 운영사·노선도에서 쓰는 약칭이 있으면 그것으로) |
| 동해선 | 흰색 굵게 | 동 |

- 배지는 **늘 번호(글자)와 함께** 쓴다. 색 원만 단독으로 쓰지 않는다.
- 배지 옆 노선 이름("계산 노선")은 배지 밖, 앱 글자색으로 쓴다.

### 1.3 노선 띠(선)와 역 점

**노선 선 = 테두리 + 속 선**
```
 ═══════   바깥 테두리: #1F3342, 전체 굵기 10px
 ███████   속 선: 노선 색, 굵기 7px  (테두리가 양쪽에 1.5px씩 보임)
```
- 테두리 덕분에 바탕이 육지든 바다든 경계 대비는 11:1 수준이 된다. 노선을 알아보는 것은 색 + 번호 배지 + 역 이름이 함께 맡는다.
- 겹쳐 달리는 구간(실제 있는지 확인 필요)이 있으면 선을 나란히 놓는다. 겹쳐 칠하지 않는다.
- 진행 띠(문제 화면 맨 위)는 같은 규칙에 굵기만 줄인다(전체 8px, 속 선 5px).

**역 점의 세 상태 — 색이 아니라 모양·굵기·글자로 구분**

| 상태 | 점 | 선(그 역까지 오는 구간) | 역 이름 | 그 밖 |
|---|---|---|---|---|
| **꺼진 역** | 빈 원, 지름 14px, 테두리 2px `#7A8691`(육지 대비 3.26), 속은 육지 색 | 가는 선 4px, `#7A8691` **점선**(6px 선 + 4px 틈) | 보통 굵기 16px, `#5E6B76`(육지 대비 4.79) | — |
| **켜진 역** | 채운 원, 지름 16px, 속 = 흰색, 테두리 3px = 노선 색 + 바깥 1px `#1F3342` | 1.3절 노선 선(실선, 10px) | **굵게** 18px, `#1F3342` | — |
| **지금 역** (내 차량이 선 곳) | 켜진 역 모양 + 바깥에 두 번째 고리(지름 28px, 2px `#1F3342`) | 켜진 선 | **굵게** 20px + 이름 밑 "지금" 꼬리표(작은 말풍선) | 내 차량 그림이 점 위에 섬. 처음 화면에 들어올 때 고리가 한 번만 커졌다 작아짐(0.6초). 계속 깜박이지 않음 |
| **환승역** | 위 상태 규칙을 따르되 모양은 **둥근 사각(캡슐)**, 관련 노선 배지를 작게(16px) 옆에 붙임 | — | — | 형제 앱의 환승역 표시와 같은 모양으로 맞춤 |
| **다음 역** (다음에 켤 역) | 꺼진 역 모양 + 테두리만 `#1F3342` 실선 2px | 지금 역에서 다음 역까지 구간만 실선 회색 4px(점선 아님) | 보통 굵기 18px `#1F3342` + "다음 역 · 2문제" | 홈에서 눈길이 갈 곳을 하나만 만든다 |

검사 방법: 화면을 흑백으로 바꿨을 때 다섯 상태가 모두 구분되어야 한다(제1·2·3색각 시뮬레이션도 함께).

### 1.4 노선도 모양 규칙 (형제 앱과 같이 쓰는 표)
| 항목 | 값 |
|---|---|
| 노선 선 | 테두리 `#1F3342` 10px + 속 노선 색 7px, 끝은 둥글게 |
| 꺼진 구간 | `#7A8691` 4px 점선 (6/4) — 형제 앱에서는 "계획 노선" 표현으로 같은 모양을 쓰기를 제안 |
| 역 점 | 일반 원 지름 16px / 환승역 캡슐 / 종점은 원 + 짧은 가로 막대 |
| 역 이름 | 시스템 sans-serif, 켜진 역 굵게. 이름은 선과 겹치지 않게 같은 쪽에 몰아 둠 |
| 노선 배지 | 1.2절 |
| 지형 색 | 형제 앱 7.1과 같음 |
| 확대 단계 | 전체(역 이름 숨김, 환승역·종점 이름만) / 노선(모든 역 이름) / 구간(진행 띠) 세 단계 |

## 2. 홈 노선도의 '점등' 표현 (MVP: 1호선만 열림)

### 2.1 목표
- 꺼진 노선은 **"잠김"이 아니라 "개통 예정"** 으로 보여야 한다. 자물쇠, 회색 덧씌우기, "잠금 해제" 같은 게임 말투는 쓰지 않는다. 철도에서 실제로 쓰는 "개통 예정", "공사 중" 말과 모양을 쓴다.
- 꺼진 것이 화면을 채우면 답답하다 → **꺼진 노선은 가볍게(가는 점선), 1호선은 무겁게(굵은 선)**.

### 2.2 전체 보기
```
┌──────────────────────────────────────────────────────────────────┐
│ 도윤 차고 ▸                                    🔊 ⚙       [부모] │
├──────────────────────────────────────────────────────────────────┤
│                      ┆                                            │
│        ┄┄┄┄②┄┄┄┄┄┄┄┄◇서면┄┄┄┄┄┄┄┄┄┄┄┄┄┄②┄┄                   │
│                      ┃                       ┄┄┄동┄┄┄┄           │
│        ③┄┄┄┄┄┄┄┄┄┄◇연산                                       │
│                      ┃                                            │
│     ①━━━━━━━━━━━━━━━┛  (1호선: 굵은 테두리 선. 켜진 구간은 노선 색, │
│                         아직 안 켠 구간은 1호선 모양 그대로 두되     │
│                         속 선 없이 흰 속 + 테두리만 = "빈 선로")     │
│                                                                  │
│  ② 2호선 개통 예정   ③ 3호선 개통 예정   ④ …   (범례, 작게)        │
│                                        1호선  6 / 40역 · 모두 48 km │
├──────────────────────────────────────────────────────────────────┤
│  다음 역: 시청 — 큰 수 · 2문제 남음                                 │
│  [        출발        ]   [ 도전 운행 ]                            │
└──────────────────────────────────────────────────────────────────┘
```
세 가지 선 표현
| 상태 | 선 | 역 |
|---|---|---|
| **1호선 켜진 구간** | 테두리 + 노선 색 속 선(1.3절) | 켜진 역 |
| **1호선 아직 안 켠 구간** ("빈 선로") | 테두리 `#1F3342` 10px + 속 흰색 7px — 선로는 깔려 있고 불만 안 들어온 모양 | 꺼진 역(빈 원), 이름 보통 굵기 |
| **개통 예정 노선**(2~4호선, 경전철, 동해선) | `#7A8691` 4px 점선. 노선 번호 배지만은 **노선 색 그대로**(정체성 유지) | 점 없음. 전체 보기에서는 이름 없음, 노선 확대에서만 회색 이름 |

- "빈 선로"가 핵심이다. 1호선은 처음부터 끝까지 선로 모양이 다 보이고, 채워질 자리가 분명하다. 아이는 "저기까지 채우면 된다"를 한눈에 본다(진행 막대를 지도에 그린 것과 같다).
- 개통 예정 노선은 배지만 색을 갖고 선은 가볍다. 존재와 위치는 보이되 1호선과 눈길을 다투지 않는다.

### 2.3 기대를 만드는 장치 (답답함 없이)
1. **1호선 위의 환승역에 다른 노선 배지를 미리 붙인다.** 서면 ◇②, 연산 ◇③, 동래 ◇④, 교대 ◇동 (FACTS.md 환승역 표 ✅). 아이가 그 역에 다가갈수록 "여기서 2호선이 열린다"는 것을 지도에서 본다.
2. **개통 예정 노선을 누르면** 아래 시트가 올라온다.
   ```
   ② 2호선 · 도형·길이 노선
   장산 – 양산, 43개 역
   준비 중이에요. 열리면 서면역에서 갈아탈 수 있어요.
                                         [닫기]
   ```
   - MVP에서 언제 열리는지 약속할 수 없으므로 **날짜나 조건을 지어내지 않는다.** "준비 중이에요"로 사실만 쓴다. 2단계에서 콘텐츠가 생기면 "1호선 서면역을 켜면 열려요"처럼 조건을 공개한다(SPEC 원칙: 조건은 미리 보여준다).
3. 개통 예정 노선에는 **반짝임, 물음표, 실루엣 보상**을 두지 않는다(뽑기 느낌, 서준 지적).

### 2.4 점등 연출 (운행 일지의 큰 소식 자리, 홈에서는 연출 없음)
| 순서 | 무엇 | 시간 |
|---|---|---|
| 1 | 앞 역에서 새 역까지 "빈 선로"의 흰 속이 **진행 방향으로** 노선 색으로 채워짐(열차가 지나가는 느낌) | 0.6초 |
| 2 | 새 역 점이 빈 원 → 켜진 원(속 흰색, 테두리 노선 색)으로 바뀌고 한 번 살짝 커졌다 돌아옴 | 0.3초 |
| 3 | 역 이름이 보통 → 굵게 | 0.15초 |
| 4 | 역이 여럿이면 다음 역으로 이어서 (최대 3개까지 연출, 4번째부터는 한 번에 켬) | 역마다 1초 |
| 5 | 마지막 역에서만 안내 방송 1회("이번 역은 양정, 양정역입니다") | 2~3초, 소리 켰을 때만 |

- 동작 줄이기 설정: 1~4를 생략하고 바로 켜진 상태로, 방송만 나온다.
- 홈으로 돌아오면 이미 켜진 상태로 보여준다. 같은 연출을 홈에서 다시 하지 않는다.

## 3. 운행 일지와 이어서 출발 카드 — 최종안

### 3.1 운행 일지 규칙
- **제목**: `①  1호선  서면 → 양정` (출발역 → 실제 도착역).
- **큰 소식 자리**(화면 높이 약 45%): 우선순위 **승급 > 새 카드 > 환승역 개통 > 일반 역 개통 > km 이정표 > 금테 완성** 중 하나만.
- **다섯 줄**: 순서는 고정, **해당 없는 줄은 빼고 위로 당긴다**("금 도장 0개" 같은 줄을 쓰지 않는다). 큰 소식으로 올라간 내용은 줄에서 다시 쓰지 않는다.
- 줄마다 한 문장, 25자 안팎. 숫자는 굵게.
- 끝 문구 "끝까지 운행 완료!"는 버튼 줄 왼쪽에 둔다(다섯 줄에 세지 않음).

| 줄 | 넣을 때 | 문구 틀 |
|---|---|---|
| ① 새로 켜진 역 | 역이 하나라도 켜졌을 때 | `새로 켜진 역  부전 · 양정` |
| ② 금 도장 | 금 도장을 받았을 때 | `금 도장 +3  [작은 카드 그림] 급행버스 4 / 5` (금테까지 남은 수) |
| ② 대신: 정비 완료 | 회복 운행에서 혼자 풀었을 때 | `🔧 정비 완료 1  — 다음에 혼자 맞히면 금 도장이 돼요` |
| ③ 거리 | 항상 | `오늘 6 km · 모두 48 km — 차고 꾸미기까지 2 km!` |
| ③ 회송이 섞인 경우 | 다시 달린 구간이 있을 때 | `오늘 6 km (회송 2 km 포함) · 모두 48 km` |
| ④ 임시 정차 | 다음 운행에 다시 낼 문제가 있을 때 | `다음 운행 임시 정차: 2곳 ▸` (누르면 시트) |
| ⑤ 다음 역 | 항상 | `다음 역: 시청 — 큰 수` |

km 표시 규칙: 내부는 소수로 쌓고, **화면에는 "모두"의 정수 부분**만 쓴다. "오늘"은 (운행 뒤 모두의 정수) − (운행 전 모두의 정수)로 계산해서 오늘 + 이전 = 모두가 화면에서 늘 맞게 한다. 오늘 값이 0이면 "오늘" 부분을 빼고 `모두 48 km — 차고 꾸미기까지 1 km!`만 쓴다(하린 유형은 덧셈이 안 맞으면 바로 알아챈다).

### 3.3 큰 소식별 문구
| 큰 소식 | 큰 글자 (1줄) | 작은 글자 (1줄, 선택) | 그림 |
|---|---|---|---|
| 승급 | `무궁화호 운행 허가` | `차고에서 새 차량이 나와요` | 차고 문이 열리고 차량이 나옴(최대 4초, 2초부터 건너뛰기) |
| 새 카드 | `새 카드: 부산김해경전철` | `차고 카드첩에 넣었어요` | 카드 앞면이 가운데로 들어옴 |
| 환승역 개통 | `서면역 개통! 2호선으로 갈아탈 수 있는 역이에요` → 너무 길면 `서면역 개통!` + 작은 글자 `2호선 환승역이에요` | — | 점등 + 환승역 캡슐에 ② 배지가 붙음 |
| 일반 역 개통 | `양정역 개통!` | — | 점등 |
| km 이정표 | `모두 100 km!` | `부산에서 ○○까지 거리만큼 달렸어요` (거리는 FACTS 확인값만, 없으면 이 줄 생략) | 지도 축소 그림에 두 도시를 잇는 선 |
| 금테 완성 | `급행버스 금테 카드 완성` | `금 도장 5개를 모았어요` | 카드 테두리가 굵어지고 ★ |

```
│  │         (차고 문 열림 → 무궁화호 출고)                          │  │
│  │                무궁화호 운행 허가                              │  │
│  │            차고에서 새 차량이 나와요                            │  │
│  └────────────────────────────────────────────────────────────┘  │
│   새로 켜진 역   교대                                              │
│   새 카드       [▭] 무궁화호 — 차고 카드첩에 넣었어요                 │
│   오늘 4 km · 모두 112 km — 차고 이름 바꾸기까지 8 km!               │
│   다음 역: 동래 — 들이와 무게                                       │
```
(임시 정차가 없어서 ④줄이 빠짐. 승급이 큰 소식이므로 새 카드는 줄로 내려옴.)

### 3.5 면허 시험에서 "정비가 필요해요"인 운행
```
│                 운행 면허 시험 — 무궁화호                           │
│  ┌────────────────────────────────────────────────────────────┐  │
│  │                정비가 필요해요                                 │  │
│  │      정비 운행 3문제를 하면 바로 다시 출발할 수 있어요           │  │
│  └────────────────────────────────────────────────────────────┘  │
│   정비할 곳     시각 계산 · 나눗셈의 나머지                          │
│   다섯 문제 해설 보기 ▸                                            │
│   오늘 3 km · 모두 108 km                                         │
│                                                                  │
│                  [  홈으로  ]   [ 정비 운행 출발 ]                  │
```
- 맞힌 개수(3/5 등)는 아이 화면에 쓰지 않는다(SPEC). "정비할 곳"은 개념 이름으로만.
- 이때만 오른쪽 버튼이 "한 번 더 운행"이 아니라 "정비 운행 출발"이다(누를 때만 시작).

### 3.6 이어서 출발 카드 (홈)
홈의 아래 띠 "다음 역" 자리를 대신한다(저장이 있을 때만).
```
├──────────────────────────────────────────────────────────────────┤
│  ⏸ 양정역에 정차 중이에요                                           │
│     지난번 그 문제부터 다시 출발해요. 힌트 ①도 같이 볼 수 있어요.       │
│  [     양정역에서 출발     ]   [ 도전 운행 ]                         │
└──────────────────────────────────────────────────────────────────┘
```
- 버튼은 **하나로 합친다**: "출발" 버튼의 글자가 `양정역에서 출발`로 바뀔 뿐이다. SPEC상 정차 문제는 어느 운행이든 첫 문제로 나오므로 "이어서 / 새로" 두 버튼을 두면 거짓 선택이 된다.
- 지도에서는 내 차량이 양정역에 서 있고 ⏸ 표시가 차량 옆에 작게 붙는다.
- **결정 필요**: 도전 운행을 눌러도 정차 문제가 먼저 나오는가? 제안 = 그렇다(일관성). 이때 도전 운행 버튼 아래에 작은 글자로 `정차한 문제부터 시작해요`.
- 정차 중인 문제가 면허 시험 문제라면 문구는 `운행 면허 시험 중이에요 — 남은 문제부터 이어서 해요`. 시험 중 맞힌 개수는 여기서도 보여주지 않는다.

## 4. 카드 앞면 제원 표기

### 4.1 영업속도와 설계속도
아이에게 두 낱말을 이렇게 풀어 쓴다.
- **운행 최고속도** = "손님을 태우고 실제로 달리는 가장 빠른 속도"
- **설계속도** = "열차를 만들 때 낼 수 있게 만든 속도"

앞면 표기 규칙
```
 최고속도   300 km/h         ← 운행 최고속도. 큰 글자, 카드의 대표 숫자
            만들 때는 352 km/h  ← 설계속도. 작은 글자, 한 줄
```
- **대표 숫자는 운행 최고속도**다. 아이가 "청룡은 몇 km/h야?"라고 물으면 지금 실제로 달리는 숫자가 정답이어야 한다(하린 유형: 믿을 수 있는 숫자).
- 설계속도는 FACTS.md에 확인값이 있을 때만 둘째 줄로 쓴다. ❌이면 **줄을 아예 빼고**(ITX-마음, ITX-새마을), "—"도 쓰지 않는다. 운행 최고속도도 ❌이면(무궁화호) `최고속도  —` + 출처 줄에 `확인 중`. 가짜 숫자를 넣지 않는다.
- 단위는 `km/h`로 쓰고, 처음 카드를 얻을 때 한 번만 "km/h = 한 시간에 가는 km"를 작은 말풍선으로 보여준다(3학년은 아직 속도를 배우지 않음).

**KTX-청룡처럼 세 숫자가 있는 경우** (FACTS.md: 지금 300 운행, 설계상 영업 320(2028년 이후 예정), 설계 352)
- 보내 주신 예시 문구 "320km/h까지 달리도록 만들었어요"는 **설계속도(352)와 헷갈린다.** 320은 "만든 속도"가 아니라 "앞으로 올릴 운행 속도"다. 그래서 이렇게 쓰기를 제안한다.
```
 최고속도   300 km/h
            앞으로 320 km/h까지 올릴 예정이에요 (2028년 이후)
            만들 때는 352 km/h
```
- 세 줄이 앞면에 너무 많으면 "앞으로…" 줄은 **뒷면의 해설 칸**으로 옮긴다. 앞면은 늘 최대 두 줄(운행 / 설계)로 고정한다.
- 뒷면 문제와 이어 쓰기 좋다: "300 km/h로 2시간 vs 320 km/h로 2시간, 몇 km 차이?" — 단, 문제에는 ✅ 값만 쓴다(청룡 ✅).

### 4.2 앞면 제원 줄 순서 (모든 열차 카드 공통)
| 줄 | 항목 | 예: KTX-이음 (FACTS ✅) |
|---|---|---|
| 1 | 최고속도 (+ 만들 때는) | 260 km/h / 만들 때는 286 km/h |
| 2 | 량 수 | 6량 (두 편성을 이으면 12량) |
| 3 | 좌석 수 | 381석 |
| 4 | 운행 구간 | 부전 – 청량리 |
| 5 | 처음 달린 날 | 2021년 1월 |
| 6 | 만든 회사 | 현대로템 |
| 끝 | 출처 · 기준일 (13px) | 코레일 등 · 2026년 10월 기준 |

- 🟡 값(보조 출처)은 카드에 쓰되 출처 줄에 그 출처 이름을 적는다. 화면에 🟡 기호는 쓰지 않는다(아이에게 의미 없음). 대신 **뒷면 문제에는 🟡 값을 쓰지 않는다.**
- 값이 형식마다 다르면(KTX-산천 좌석 363~410석) 범위 그대로 쓴다: `363~410석 (형식마다 달라요)`.

### 4.3 역사 카드 (지금은 안 다니는 차량, 예: SRT)
FACTS.md: SRT 2016-12-09 첫 운행, 2026-08-31 운행 끝, 2026-09-01부터 KTX로 통합(차량 관련 서술은 표 그대로 옮기되 문구 확정 전 다시 확인 필요).

시각 구분 — **색을 빼지 않는다**
- 회색(흑백) 처리는 카드첩에서 **"아직 못 얻은 카드"** 의 표현과 겹친다. 역사 카드가 회색이면 아이는 "안 받은 카드"로 오해한다. 그래서 그림은 그대로 컬러로 둔다.
- 대신 세 가지를 함께 쓴다.
  1. **카드 맨 위 띠**: 진한 글자색 바탕에 흰 글자 `운행 기록  2016.12 – 2026.8` (모양 + 글자)
  2. **테두리 모양**: 가는 이중선(일반 카드는 단선, 금테는 굵은 선 + ★). 세 종류가 선 모양만으로도 구분된다.
  3. **제원 문장을 과거형으로**: `최고속도 300 km/h로 달렸어요`, `운행 구간 수서 – 부산 (확인 필요)`
- 뒷면 맨 아래에 한 줄: `2026년 8월 31일에 마지막으로 달렸어요.` 이어지는 사실(통합 내용)은 FACTS 문구가 확정된 뒤에만 넣는다.

```
 ┌══════════════════════════┐   ← 가는 이중선
 ║ 운행 기록  2016.12–2026.8 ║   ← 맨 위 띠
 ║ ┌──────────────────────┐ ║
 ║ │    (SRT 측면도, 컬러)   │ ║
 ║ └──────────────────────┘ ║
 ║ SRT                 특별 ║
 ║ 최고속도  300 km/h로 달렸어요║
 ║ 량 수     10량            ║
 ║ 처음 달린 날 2016년 12월    ║
 ║ 만든 회사  현대로템         ║
 ║ 출처 · 2026년 10월 기준     ║
 └══════════════════════════┘
```

### 4.4 카드 종류 한눈에 (카드첩 안에서)
| 종류 | 테두리 | 맨 위 띠 | 그림 | 그 밖 |
|---|---|---|---|---|
| 아직 못 얻은 카드 | 점선 | 없음 | **실루엣**(회색) | 아래에 얻는 조건 글로 공개: `무궁화호 단계에 오르면 받아요` |
| 일반 카드 | 단선 | 없음 | 컬러 | 진행 막대(금 도장 n / 기준) |
| 금테 카드 | 굵은 선 + ★ | 없음 | 컬러 | 진행 막대 대신 `금테 완성` |
| 특별 카드 | 단선 | `특별` 띠 | 컬러 | 얻은 조건을 뒷면에 기록 |
| 역사 카드 | 가는 이중선 | `운행 기록 연도–연도` 띠 | 컬러 | 제원 과거형 |

- 특별 카드이면서 역사 카드(SRT)는 띠를 `운행 기록` 하나로 하고, 오른쪽 위에 `특별`을 작게 쓴다(띠를 두 개 겹치지 않는다).
- 역사 카드도 금 도장과 금테가 가능하다면 굵은 선 안쪽에 이중선을 두는 대신 **이중선 + ★**로 표현한다(결정 필요: 역사 카드에 금테를 둘지).

## 6. 결정이 필요한 것
1. 도전 운행을 눌러도 정차한 문제가 먼저 나오는가(제안: 예).
2. 역사 카드에 금테를 둘지.
3. 경전철 배지 글자(`경`) — 실제 쓰이는 약칭 확인 필요.
4. 노선 테두리 규칙을 형제 앱에도 전달할지(사용자 결정).
