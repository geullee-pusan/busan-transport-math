# 부산 교통 수학

부산 도시철도 노선도를 따라가며 배우는 초등 수학 학습 앱입니다. 문제를 풀면 1호선 역에 하나씩 불이 켜지고, 내 차량이 실제 역 사이 거리만큼 달립니다.

- 2022 개정 교육과정 3~6학년 수학을 실력에 맞춰(학년이 아니라) 기초부터 경시 수준까지 다룹니다.
- 태블릿 브라우저에서 홈 화면에 추가해 오프라인으로 쓸 수 있습니다.
- 광고, 결제, 사용 추적, 외부 연결이 없습니다. 진도는 기기에만 저장됩니다.

자세한 기획은 [docs/SPEC.md](docs/SPEC.md)에 있습니다.

## 개발
```
npm install
npm run dev
npm test
npm run build
```

- 열차진입 안내음·방송: 공공데이터포털 3033578 부산교통공사_부산도시철도 역사 안내방송(이용허락범위 제한 없음)
- 교육과정: 교육부 고시 제2022-33호 [별책 8] 수학과 교육과정
